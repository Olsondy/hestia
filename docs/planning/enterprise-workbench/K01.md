## Problem Statement

企业方案里的家具只是固定氛围道具，无法表达“软装方案”；现有家具布局与视觉风格只支持单层个人项目，素材也偏少。

## Solution

建立企业工作空间的软装风格目录（有版本），按房间类型给出家具组合与材质；扩充家具与软装素材；让家具布局支持多楼层别墅与房间类型。

## User Stories

1. As an 企业成员, I want 企业有几套软装风格（如现代简约、新中式、轻奢）, so that 方案能体现软装搭配。
2. As a 客户, I want 效果图里的家具、灯具、地毯随风格变化, so that 看出不同风格的整体感觉。

## Implementation Decisions

- 软装风格 = 每类房间（客厅、餐厅、卧室、书房、茶室等）的家具组合（款式、尺寸、相对位置规则）+ 布艺与配色材质 + 灯具；属于工作空间目录，版本不可变，可下架。
- 家具与软装素材在 `scene-runtime` 中程序生成（与 V01 道具同一管线），每套风格至少覆盖客厅、餐厅、卧室；包括沙发、茶几、餐桌椅、床、柜体、灯具、地毯、挂画、绿植。示意素材，不含真实品牌。
- 家具布局支持多楼层：按楼层与房间类型放置，校验沿用候选的碰撞与通行检查（按楼层）；门、楼梯与饰面不被遮挡。
- 演示目录提供 3 套示意风格；示例别墅的固定道具改为由风格生成。

## Testing Decisions

- [ ] 几何夹具：三套风格在示例别墅各房间放置后无碰撞、不挡门与楼梯、不越出房间。
- [ ] HTTP + PostgreSQL：目录版本与下架、工作空间隔离。
- [ ] 渲染：三套风格的室内效果图截图复核（独立视觉复核）。

## Out of Scope

企业真实家具素材导入；客户自由摆放。
