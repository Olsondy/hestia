## Problem Statement

模型管理的界面还没有设计：平台管理后台、企业设置里的模型与用量、Agent 助手里的选模型，实现前需要先确认页面、信息层级与操作流程。

## Solution

交付电脑端可点击交互原型，使用演示数据，不接服务端；视觉沿用企业工作台定稿的柔和中性 B 悬浮。

## User Stories

1. As a 产品负责人, I want 在浏览器里点完平台管理员与企业管理员的主要流程, so that 判断页面和流程是否合适。
2. As a 产品负责人, I want 看到各类状态与异常（检查未通过、额度用完、模型被停用、未开通）, so that 实现时不遗漏。

## Implementation Decisions

- 2026-11-12 用户审阅反馈：列表上要能测试每个模型服务的连通；模型 ID 要从服务获取、一个服务可启用多个、启用的都能在 Agent 中选择；不要卡片套卡片（准则 L4）。已按此调整。
- 2026-11-13 按 ADR-0018 补充：后台企业页加「进入工作台（只读）」与月度额度“不限”，页头区分超级管理员与平台管理员；企业工作台加只读的平台支持模式（页头标识、写操作拦截）、「企业设置 · 访问记录」与额度“不限”。待用户审阅。
- 平台管理后台 `example/prototypes/admin-console/`：登录；模型服务列表（每个服务测试连通、全部测试、连通失败提示）；登记与管理模型服务（三种协议、服务级兼容设置、密钥末四位、超时与总并发；获取模型列表、启用多个模型 ID、服务不提供列表时手动添加）；模型设置（显示名称、模型级参数、单价与单价记录）；按模型的接入检查（进行中、通过、未通过）；停用确认；企业列表与分配（可用模型、月度额度、并发上限）；用量（按月、按企业或模型、导出）；审计记录；企业域名上访问显示不存在。
- 企业工作台原型 `example/prototypes/enterprise-workbench/` 补充：企业设置 · 模型（启用、设默认、平台已停用、额度摘要）与用量（按成员或模型）；Agent 助手选择模型（列表、切换后从下一步生效、所选模型被停用、额度用完、未开通、服务无响应）。
- 1440 为主，兼顾 1280 与 1024；浅色与深色两套主题。演示数据中性命名，不代表任何供应商。

## Testing Decisions

- [x] 无浏览器检查（jsdom，2026-11-13 复查：后台 32 个、工作台 46 个状态）：两个原型审阅导航中的全部状态都能渲染、无脚本错误；额度“不限”的保存与审计、进入工作台、只读模式拦截发消息与写操作、访问记录可走通；登记 → 接入检查 → 分配 → 审计，选模型 → 切换 → 生成，设置页启用与设默认等流程可走通。
- [ ] 浏览器 1440 / 1280 / 1024、浅色与深色逐页截图自查（需用户同意启动浏览器）。
- [x] 用户审阅通过（2026-11-14，用户在浏览器中查看两个原型后确认“没有什么问题”）：AM01–AM05 的界面部分可以开始；数据、接口与权限部分不受此阻塞。
