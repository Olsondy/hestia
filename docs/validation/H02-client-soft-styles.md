# H02 H5 客户端软装风格切换验证

日期：2026-11-03。范围：工单 #57。本机 PostgreSQL、Next.js dev（127.0.0.1:3000）、出图 Worker 与图纸转换 Worker；演示数据 `pnpm demo:seed --reset` 后由出图 Worker 生成 6 张效果图。

## 实现要点

- **软装风格接入 K02**：方案页（标签、软装区块、方案对比的“软装”行）、确认页与已确认页显示方案修订的软装风格；调整页“软装风格”列出该方案的可选风格；首页列出企业目录中的风格（示意素材）。删除本机演示数据（`softStyleStore`）。没有风格的旧方案只显示硬装，调整页只有“硬装石材”。
- **统一出图**（ADR-0010）：新增 `POST /api/client/{entry}/requests/{id}/schemes/{schemeId}/adjust-batch`，一次提交多处石材 / 规格 / 铺法 / 波打线修改和可选的软装风格，排版校验通过后生成一个修订、只出一次图；任何一处冲突时整批不生效，原因显示在调整页；没有变化时提示“方案没有变化”。`adjustBatch` 改为调用这个接口，原来逐个饰面调用的预留实现删除。单项调整与切换风格接口保留。
