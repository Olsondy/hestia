# 根域名是官网入口页：客户 H5 与企业工作台两个入口

用户于 2026-11-04 明确：正式域名的根路径是官网入口页，上面放客户 H5 和企业工作台两个入口；目前以演示企业示例，但要按以后的正式官网来做。本决定覆盖 ADR-0007 与 W01 中“`HESTIA_HOME_ENTRY` 设置时根路径直接重定向到企业客户端、不显示工作台入口”的部分。

## 决定

- **三个入口**：客户 H5 `/c/{企业}`、企业工作台 `/w/{企业}`、个人工作台 `/studio`。个人工作台首期不开放（见 `status.md`），官网入口页不展示、不链接；地址保留给验证脚本，成员邀请链接（`pnpm invite`）也指向 `/studio?invite=…`。
- **根路径 `/`**：始终是官网入口页（家居杂志方向，独立布局与样式 `app/(site)`），展示客户与企业成员两扇入口。
- **入口接到哪家企业**：`HESTIA_HOME_ENTRY` 的含义改为“官网入口接到的企业”，不再触发重定向；演示为 `demo-home`。未设置时两扇入口提示“请使用合作企业提供的链接或分享码进入”，不指向不存在的页面。
- **`/w` 总入口**：配置了企业时跳到该企业工作台；未配置时提示使用企业提供的工作台地址。以后接入多家企业时，在这里做“成员登录后选择工作空间”，客户入口改为输入分享码；入口页本身不需要重做。
- **演示提示**：模拟短信（演示部署）下，入口页页脚注明“演示环境 · 数据、尺寸与效果图均为示意”。

## 影响

- 企业客户不会在根路径直接进入 H5，需要点一次“进入客户端”；企业分享给客户的链接和分享码不受影响。
- 依赖根路径进入个人工作台的验证脚本已改为 `/studio`；`validate:client-h5` 改为从入口页点进客户端。
