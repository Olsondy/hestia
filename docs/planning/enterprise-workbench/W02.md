## Problem Statement

成员需要在一个地方看到所有线索并了解每位客户的完整情况。

## Solution

实现线索列表（筛选）与线索详情（客户、需求、方案、确认与留言、跟进状态与备注、分享与绑定记录）。

## User Stories

1. As an 企业成员, I want 按状态、跟进状态、是否请求联系筛选线索, so that 快速找到要处理的客户。
2. As an 企业成员, I want 在详情里看到方案效果图对比、客户确认的修订和留言, so that 联系前了解全部情况。
3. As an 企业成员, I want 修改跟进状态并追加备注, so that 团队同步进展。

## Implementation Decisions

- 按获批原型实现；数据来自 D06–D08 线索接口与 S02。
- 方案效果图使用成员可见的出图结果；3D 查看复用 `scene-runtime`。
- 客户手机号完整显示给成员（用于联系），列表中脱敏。
