# D04 饰面与石材铺贴验证

日期：2026-11-02。范围：工单 #33。本机 PostgreSQL 14（独立库），未启动 Next.js。

## 实现要点

- **饰面**（固定事实）：地面（房间或单独轮廓）、墙面（某一侧、可限定范围、扣除门窗洞）、楼梯踏面与踢面，契约见 `packages/contracts/src/finishes.ts`。
- **铺贴方案**：引用目录石材与版本，记录规格、铺法（直铺、工字、人字、斜铺）、缝宽与颜色、起铺点、方向、可选波打线；方案内嵌所引用的石材版本副本，渲染离线可复现。
- **排版引擎**：`packages/finishes/src/layout.ts`、`plan.ts`，纯 TypeScript；输出整块与切块几何和数量，报告窄条（提示）、超出饰面、人字铺需要条形石材、波打线过宽（冲突）。
- **石材目录**：工作空间私有表 `workspace_stones`（迁移 0020），版本不可变，可标记失效。演示石材为仓库代码程序生成的示意纹理（`demo-stones.ts`），无照片或企业素材。
- **候选链路**：`set-tiling` / `clear-tiling` 进入候选命令，选择石材时只接受目录中有效版本；检查新增 `surface-design` 项，改动的铺贴遇失效版本为冲突、未改动的为提示；采用与撤销保存前后铺贴，变化类型新增 `surface`。
- **渲染**：`packages/scene-runtime/src/finish-surfaces.ts`（入口 `createFinishMeshes(snapshot, levelIds)`，由 `createSceneModel` 调用）与 `stone-texture.ts`。每块石材独立网格、独立纹理窗口与微倒角，缝线为真实间隙；抛光与哑光通过 roughness、clearcoat 与细部凹凸区分，材质为 `MeshPhysicalMaterial`，场景环境贴图与灯光直接生效。
- **演示别墅**：项目模板 `demo-villa` 带三层、饰面与示例铺贴（客厅大板直铺加深色波打线、餐厅人字铺、过厅斜铺、电视背景墙工字铺、楼梯踏面）；别墅家具作为不可移动的氛围道具存为固定物品。
- **多楼层摆放检查**：`validatePlacement` 改为只校验目标物品所在楼层，修复多层项目一律报 `INVALID_GEOMETRY` 的问题（D03 遗留）。
