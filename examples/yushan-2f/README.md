# 玉山二层示例

该示例来自业主的手绘图、生活记忆和多轮纠正。仓库不包含业主原始截图、地图定位图或聊天记录。

## 已确认关系

- 房屋共四层，布局和旋转折返楼梯方式重复；仅展示二楼代表层及上下连接梯段。
- 图上北下南、右东。二楼不是顶楼；卧室南侧墙夏季傍晚很热，现有空调开启后能降温。
- 独立电竞房由大客厅隔出，西南角柱子保留。客厅西侧已有电视墙。
- 书房西南角为阳台门。阳台向西凸出；书房与下方楼梯、过道整块东西宽度对齐。
- 书房南门与卫生间北门相对，中间有过道。客厅入口为大滑门，与卧室门斜对。
- 卧室西侧、靠卫生间的整排固定柜不可移，靠门一端避让内开门。
- 原空调在卧室东北侧内墙，离东窗墙约 1.5 m；保留位置。
- 床可移动，床头保持朝北侧内墙，远离南侧热墙。
- 一楼到二楼：11 级 → 平平台 → 约 5 级 → 平平台 → 11 级。
- 扶手在中央空隙一侧，连接楼层过道护栏并继续向楼上延伸。

## 尚未实测

卧室西墙至东窗墙按记忆超过 8 m，模型暂取墙位跨度 8.3 m，包含原柜深度。书房左右暂取 3 m，阳台凸出暂取 0.9 m，主体进深仍暂取 9 m。原始 80–90 ㎡估计与后来尺度修正尚未闭合，不能据此输出准确装修面积。

楼梯 27 级在暂定范围内被压缩表达，平台、踏步高宽和净空不可从模型读取为施工尺寸。上楼梯段临时复用同形几何，其具体级数未再次核实。

窗洞、门扇开启细节、固定柜外观及尺寸、洁具位置、层高、墙厚、梁柱尺寸、灯具点位均含示意成分。书房阳台侧窗是按用户要求补充的视觉表达，尺寸与窗型待核实。

## 家具方案

- A 原木会客：三人沙发加单椅；卧室单椅阅读角；书房北桌东柜。
- B 奶油舒展：双人模块加贵妃位；卧室床进一步向东约 43 cm 并加床尾凳；书桌转东墙。
- C 轻中式对坐：木框坐榻加茶桌；卧室东南双椅对坐；书桌离北墙。

所有家具是体量和布局提案，不对应具体商品。颜色不是结构或隔热性能证据。

`assumptions.json` 是 R1.0 的可读快照；运行模型目前以源码为准。
