## Problem Statement

客户需要用手机号登录企业入口，演示阶段没有真实短信服务，但验证逻辑必须按正式要求实现。

## Solution

实现手机号验证码登录，短信发送经适配器，提供 `SMS_PROVIDER=mock` 模拟发送。客户从企业入口登录时建立客户关系。

## User Stories

1. As a 客户, I want 用手机号和验证码登录, so that 不需要密码。
2. As a 客户, I want 演示环境能拿到验证码, so that 没有真实短信也能登录。
3. As a 客户, I want 从企业 H5 入口登录后自动成为该企业的客户, so that 能提交方案需求。
4. As a 维护者, I want 生产环境无法启用模拟发送, so that 演示开关不会上线。
5. As a 维护者, I want 验证码有时效、错误次数和频率限制, so that 防止滥用。

## Implementation Decisions

- 账号全平台唯一；手机号登录与现有 Better Auth 会话体系一致，同一手机号只对应一个账号。
- 验证码只存哈希，限定时效、错误次数，按手机号和来源限频；限额数值为可配置项。
- 短信发送适配器：`mock` 不外发，验证码写入服务端日志，并仅在模拟模式下通过响应返回演示验证码，供 H5 显示。本票不做页面。`NODE_ENV=production` 且为 `mock` 时服务启动失败。
- 企业入口由 H5 路径中的工作空间标识确定；首次登录建立客户关系，重复登录不重复创建。客户不是工作空间成员。
- `.env.example` 记录开关，不提交任何真实凭据。

## Testing Decisions

- [ ] 正确验证码登录成功；过期、错误次数超限、频率超限分别被拒绝且有明确错误码。
- [ ] 模拟模式下接口返回演示验证码；非模拟模式下响应不含验证码。
- [ ] 生产环境配置模拟发送时启动失败。
- [ ] 从企业入口登录建立一次客户关系；客户无法访问该企业的其他客户项目或成员接口。

## Out of Scope

真实短信服务商、微信手机号快速验证、小程序登录、成员和个人用户改用手机号登录。
