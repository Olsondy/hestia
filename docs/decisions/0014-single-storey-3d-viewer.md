# 3D 只看一层的软装与硬装，不做整栋与多楼层浏览

用户于 2026-11-04 指出：3D 的目的是让客户看清一层的软装和硬装效果，“整栋鸟瞰”和逐层鸟瞰客户不关心，还浪费性能。DXF 导入本来就只有一层；多层只来自示例别墅。

## 决定

- **只显示一层**：交互式 3D（H5 客户端、企业工作台方案 3D）只加载一层，默认选硬装地面铺得最多的那一层（示例别墅为一层），不提供楼层切换。
- **保留入户查看**：人眼视高的入户镜头照旧保留，并且只加载所在楼层，不再连带渲染其他楼层。
- **去掉整栋鸟瞰**：预设镜头改为本层的“全层立体浏览”加入户房间；不再展示整栋和逐层鸟瞰。
- **全层立体浏览 → 房间 → 入户**（同日用户确认）：默认进入全层立体浏览，墙体剖到约 1.1 m（远侧外墙和朝向镜头的石材墙面保留全高），晴天侧光的“模型感”光照，房间标签跟随镜头；点标签或房间地面，镜头飞近该房间并显示地面石材、规格与铺法，点「入户查看」进入人眼视高的写实画面。每个有名称的室内房间都可入户。
- **色调保持写实**：全层立体浏览只调光比与阴影，色调映射仍为 Neutral（不用 ACES），石材颜色在各种看法下一致。全层光照不随风格预设：侧光太阳与视线约成 77°、高度角约 50°，太阳明显强于天光与环境光，家具投影清楚（与 hestia-creation 对比确定）；入户仍用风格预设灯光。
- **只突出设计内容**：标签、房间按钮与全层取景只覆盖铺了石材的房间和普通室内房间；没铺石材的庭院、露台与车库、设备间、储藏、洗衣、空调位不显示标签，其中的物件隐藏，庭院、露台的地面也隐藏。只影响交互 3D，场景数据和效果图不变。图纸里没有房间文字时，交互 3D 按面积命名为“房间 1、2…”（小于 1.5 m² 不计）。
- **平面图**（同日用户要求）：H5 与工作台的查看方式为「效果图 / 3D / 平面图」。平面图复用同一场景，正上方俯视，在楼板以上 1.2 m 剖切，只平移缩放，提供真实材质、白模、线框三种显示；它展示的是设计结果，不是客户上传的原始图纸。
- **夜景**：3D 提供日景 / 夜景切换，夜景点亮灯具；平面图固定日景。
- **竖屏**：交互全层视角从四个正交方向中选户型显示最大的一个，平面图在明显更合适时旋转 90°；标签重叠时次要标签缩成可点的圆点。H5 方案面板可拖动，分最小化（只留横条与底部操作栏）、默认、展开三档，操作栏任何高度下都固定在底部。
- **数据层不变**：户型与场景契约仍支持多层（运行时的 `building` / `section` 视图留给验证脚本使用），只是不在界面上展示。
- **方向**：后续投入放在单层的观看手感与软装、硬装质感上（参照 hestia-creation 原型的剖切、聚焦和漫游）。

## 影响

- 后台效果图的入户镜头同样只加载本层，渲染更轻。
- 以后真有“一个项目多张楼层图纸”的需求时，另行决定是否加楼层切换。
