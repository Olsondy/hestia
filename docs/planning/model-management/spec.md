## Problem Statement

企业端要接入真实模型辅助出方案，但现在的模型写死在代码与部署配置里：运行时只从 `HESTIA_MODEL_*` 环境变量读取一个模型，准入靠代码里的配置指纹（`PLATFORM_ADMISSION`）。换模型要改代码或重启，无法按企业区分可用模型，成员不能选择，多家企业共用时没有额度，用量只能按任务粗略汇总，无法按模型折算金额与企业结算。

## Solution

按 [ADR-0018](../../decisions/0018-admin-managed-models-per-enterprise-quota.md)：

1. 新增平台管理员、超级管理员角色与 `/admin` 管理后台（仅 `HESTIA_ADMIN_HOST` 指定的后台域名）。
2. 平台管理员登记模型服务（地址与密钥），从服务获取模型 ID 并启用其中多个（不预置供应商，只有协议适配器；首期支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议，调用层沿用 AI SDK Core），密钥加密保存，经接入检查准入。
3. 平台管理员为每家企业分配可用模型、月度额度（元）与 Agent 并发上限；企业管理员在已分配的模型里启用、设默认。
4. 每次模型调用前按金额预占额度，结束后按实际用量结算；记录调用级用量并提供平台与企业两级统计。
5. 成员在 Agent 交互处选择本企业已启用的模型；运行时改从模型登记读取。

## User Stories

1. As a 平台管理员, I want 在后台登记任意供应商的模型与密钥, so that 换模型不需要改代码或重新部署。
2. As a 平台管理员, I want 新模型先通过接入检查才能分配, so that 企业不会用到不可用的模型。
3. As a 平台管理员, I want 给每家企业指定可用模型和月度额度, so that 费用可控、可结算。
4. As a 平台管理员, I want 按企业、模型、月份查看用量与金额并导出, so that 能和企业结算。
5. As an 企业管理员, I want 在分配给本企业的模型里启用、设默认, so that 成员用合适的模型。
6. As an 企业管理员, I want 看本企业各成员的用量与本月剩余额度, so that 掌握使用情况。
7. As an 企业成员, I want 在 Agent 对话处选择模型, so that 按任务需要取舍速度与质量。
8. As an 企业成员, I want 额度用完或模型不可用时得到明确说明, so that 不会以为系统出错。

## Implementation Decisions

- 平台管理员授予已有邮箱账号，命令行授予与撤销；`/admin` 只在 `HESTIA_ADMIN_HOST` 上提供，其他域名按不存在处理。独立部署沿用同一套页面，平台管理员由企业指定、录入企业自己的密钥（ADR-0018 补充）。
- 超级管理员（我方，排查问题用）：可进入后台与所有企业工作台，不出现在成员列表；进入后只读，写接口在服务端拒绝；每次进入写审计，企业管理员可在「企业设置 · 访问记录」查看（AM06）。
- 月度额度可设为“不限”，只计量不停止。
- 模型服务：服务名称（标注）、协议、地址、密钥、协议级兼容设置、超时、总并发上限；可测试连通、获取模型列表（`GET /models` 或 `/v1/models`，不支持时手动添加）。模型：服务里启用的模型 ID，各自有显示名称与说明、最大输出、模型级参数、单价（有版本）、状态。密钥 AES-256-GCM（`HESTIA_SECRET_KEY`），只显示末四位。
- 协议适配器：Chat Completions 用 `@ai-sdk/openai-compatible`，Responses 用 `@ai-sdk/openai`，Anthropic Messages 用 `@ai-sdk/anthropic`；三个包与 `ai` 共用同一版本的 `@ai-sdk/provider`。运行器只看到统一的流式文本、工具调用、结束原因与 token 用量；各协议的有限兼容设置随登记保存。
- 接入检查按模型 ID 真实调用，验证连通、流式、工具调用与 Hestia 协议，记录证据；改服务的地址、协议、兼容设置或模型的调用参数后失效。
- 额度按金额、按 Asia/Shanghai 自然月；调用前预占“输入估算 + 最大输出”，结束结算；未知用量按预占额计入并标记未核对；超额不发出调用，任务停在可恢复状态。
- 企业并发上限沿用 M03 按企业公平队列；模型总并发上限跨企业共享，超出排队。
- 不自动换用其他模型；所选模型不可用时提示改选。
- 所有管理操作写审计记录。

## Testing Decisions

- HTTP + PostgreSQL：非平台管理员（含企业管理员）访问 `/admin` 接口一律拒绝；企业域名上不可达；密钥不出现在任何响应与日志中。
- 额度：并发调用不会让已用 + 预占超过额度；结算退回多余；未知用量按预占计入。
- 跨企业：A 的成员看不到 B 的模型分配与用量；A 不能选未分配给 A 的模型（纳入 M06 隔离矩阵）。
- 真实模型：接入检查与一次 Agent 调用用管理员录入的真实模型验证；未录入前记为未验证。
- 浏览器：管理后台与企业设置页 1440；Agent 模型选择 1440。

## Out of Scope

共享部署下的企业自带密钥（BYOK）；在线支付与账单；按成员的额度；平台管理员双因素认证（另行决定）；Agent 的工具范围（K03 另行决定）。
