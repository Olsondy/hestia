## Problem Statement

客户提交方案需求需要导入自家图纸。栅格识图已暂停，演示要求 DXF 自动转换，其他格式如实标注为辅助转换。

## Solution

后台 Worker 将 DXF 转为 HouseSpec 并经 `floorplan-import` 生成空间候选；其他格式进入辅助转换状态，由成员通过接口导入 HouseSpec。

## User Stories

1. As a 客户, I want 上传 DXF 后自动得到我家的空间, so that 方案基于真实户型。
2. As a 客户, I want 上传其他格式时看到需要辅助转换, so that 不会误以为已经识别。
3. As an 企业成员, I want 为辅助转换的项目导入 HouseSpec, so that 客户能继续得到方案。

## Implementation Decisions

- 转换器改编自 house-plan-designer `cadvec`（MIT，保留声明），以独立进程在后台任务中运行，输入大小与格式受限，超时与失败有明确状态；不在 Web 请求内执行。
- 转换结果经 `floorplan-import` 与 D03 契约校验，生成空间候选；尺度来自 DXF 单位，矛盾标注列出，校验不通过进入待审核。
- 本票只提供上传与状态接口，页面在 H5 实现中完成。
- 非 DXF 文件只保存为资源并进入“辅助转换”状态；成员接口导入 HouseSpec 后继续流程。不恢复 T02/T11。
- 上传资料属于客户与对应工作空间，遵守现有私有存储与授权。

## Testing Decisions

- [ ] 授权或合成的 DXF 样例转换后墙体、洞口与尺寸和标注一致；失败、超时与超限输入有明确状态。
- [ ] 重复投递与 Worker 重启不重复生成候选。
- [ ] 非 DXF 进入辅助转换；成员导入 HouseSpec 后项目可继续；其他客户无法读取上传文件。

## Out of Scope

栅格图片和 PDF 自动识图、DWG、手动描图界面。
