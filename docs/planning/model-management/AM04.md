## Problem Statement

用量只按任务粗略汇总在事件里，无法按模型、成员统计，也无法按单价折算金额与企业结算。

## Solution

记录每次模型调用的用量与当时单价，提供平台与企业两级统计页面和导出。

## User Stories

1. As a 平台管理员, I want 按月、企业、模型看调用次数、token 与金额并导出 CSV, so that 与企业结算。
2. As an 企业管理员, I want 按月、成员、模型看本企业用量与剩余额度, so that 掌握使用情况。

## Implementation Decisions

- 调用记录：企业、成员、任务、模型登记与单价版本、输入与输出 token（未知标记未核对）、金额、耗时、结果状态；与 AM03 的预占结算同一事务写入。
- 平台后台「用量」页与企业工作台「设置 · 用量」；`pnpm usage:report` 增加按模型与金额的汇总。
- 金额以分为单位存储整数，展示时换算为元。

## Testing Decisions

- [ ] PostgreSQL：合成调用记录按月（Asia/Shanghai）、企业、模型、成员汇总正确；改价前后的调用按各自单价折算；未核对用量单独列出。
- [ ] HTTP：企业管理员只能看本企业；成员不可见。
- [ ] 真实浏览器：两个统计页 1440；CSV 导出内容与页面一致。

## Out of Scope

账单、发票与在线支付。
