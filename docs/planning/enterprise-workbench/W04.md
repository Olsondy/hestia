## Problem Statement

成员需要在界面上为客户预置方案并分享，处理绑定申请、撤销与解绑。

## Solution

实现预置方案、分享码分享（可选指定手机号，ADR-0012）、审批绑定申请、撤销分享码、解绑客户与操作记录。

## User Stories

1. As an 企业成员, I want 选饰面和石材为客户预置示例别墅方案, so that 先发方案给客户。
2. As an 企业成员, I want 创建分享后立即复制分享口令（含分享码）, so that 发给客户在 H5 或小程序里打开。
3. As an 企业成员, I want 批准或拒绝绑定申请、撤销分享码、解绑客户, so that 处理发错与冒认。

## Implementation Decisions

- 按获批原型实现，复用 D08 接口；分享码与分享口令只在创建时显示一次，关闭后不可再查看，界面明确提示；原型中的链接与绑定码按 ADR-0012 改为分享码，有效期选 7 / 30 / 90 天。
- 撤销、解绑、拒绝需要二次确认；操作记录按时间显示在线索详情。

## Testing Decisions

- [ ] 真实浏览器：预置方案 → 指定手机号分享 → 客户端输入分享码、用该手机号绑定 → 成员看到绑定记录；不指定手机号分享 → 客户输码后登录即绑定；申请 → 批准；撤销后分享码失效。

## Out of Scope

协作者邀请；成员代客户调整方案。
