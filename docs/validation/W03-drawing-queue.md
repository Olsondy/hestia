# W03 图纸整理队列验证

日期：2026-11-03。范围：工单 #48（按 ADR-0013 缩小为整理队列）。本机 PostgreSQL、Next.js dev（127.0.0.1:3000）、图纸转换 Worker；未运行出图 Worker。

## 实现要点

- **入口**：照片、PDF、DWG 与客户交给企业的图纸进入队列（`assisted_conversion`）；「今日」“待整理图纸”、线索列表快捷筛选与线索详情底部“整理图纸”进入整理页 `/w/{企业}/leads/{id}/assist`。
- **整理页**（按原型辅助转换页）：步骤（下载客户图纸、整理户型、导入户型并校验、出方案并发布）、客户信息；下载原图；导入 HouseSpec JSON（非 JSON 直接提示），显示校验通过的楼层 / 房间 / 墙 / 门窗数，或未通过的原因；核对提示译为中文并合并同类（如“门窗高度按默认值估算（6 处）”）。
- **出方案**：新增成员接口 `POST /api/workspaces/{id}/leads/{requestId}/generate`（幂等）。与 DXF 自动出方案共用同一步骤，但失败时把原因返回成员、需求不变，客户仍看到“排队处理中”；成员导入户型后、确认前客户仍是“排队处理中”。通过排版校验的方案直接发布。
- **全部审核**：仅对开启该设置的企业，线索详情显示“发布给客户”（二次确认）。
- **预留**：模型识别户型草稿放在导入之前，首版不调用模型。
