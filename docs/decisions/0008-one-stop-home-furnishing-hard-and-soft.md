# 企业场景扩展为一站式家装：方案同时包含硬装与软装，工作台由 Agent 辅助出方案

[ADR-0007](0007-shared-core-personal-and-enterprise-workspaces.md) 把企业场景定为石材硬装的饰面铺贴，家具只作预设氛围道具。实际的企业客户大多同时提供石材铺贴与全屋家装（一条龙），需要向他们的客户展示“硬装 + 软装”的完整效果；企业成员也需要更快地出整套方案。因此扩展企业场景的范围，共享内核与工作空间的边界不变。

## 决定

- **定位**：企业场景面向一站式家装企业（含石材铺贴与全屋软装）。演示企业统一称“演示家装企业”（标识 `demo-home`），石材铺贴仍是核心卖点。
- **整体方案**：一个方案同时包含**硬装**（饰面铺贴：石材、规格、铺法、波打线）与**软装**（家具布局与软装风格：家具款式、布艺、灯具、配色与材质）。硬装沿用 D04 的饰面与铺贴模型；软装沿用已有的家具布局方案与视觉风格，扩展到多楼层与企业工作空间。
- **软装风格**：企业工作空间私有的软装风格目录（与石材目录一样有版本），按房间类型给出家具组合与材质。演示使用示意素材，不含真实品牌家具。
- **工作台由 Agent 辅助**：企业成员在工作台中通过 Agent 出整套方案（硬装 + 软装）。Agent 只使用受限领域工具，产出候选，成员核对后发布给客户，沿用候选、展示、选择、采用的链路与 ADR-0002 的执行层约束。企业内部使用 Agent，不属于面向公众的服务。
- **客户端不变的边界**：客户端仍不调用生成式 AI。客户可以在方案给定的 2–3 套软装风格中切换，确定性重新出图；家具布局由企业或 Agent 确定，客户不能自由摆放家具。硬装调整沿用 D07。
- **演示**：客户端流程保持离线可用；工作台的 Agent 演示需要联网调用模型，另准备 Agent 预先生成的方案与对话记录，网络不可用时直接展示。

## 考虑过的替代方案

- **只做硬装**：实现最少，但不符合一站式家装企业的卖点，演示说服力弱。
- **客户端也开放 Agent**：体验最自然，但属于面向公众的生成式 AI，须先备案或登记（ADR-0007 的门槛不变）。
- **软装只用固定氛围道具**：现有效果即是如此，无法体现“软装方案”，也无法让客户比较风格。
- **全程离线演示 Agent（本地模型）**：部署与效果风险高，不适合首版。

## 影响

- ADR-0007 中“家具与电器只作为预设氛围道具，客户不能自由摆放”修订为：家具由方案确定，客户可选预设软装风格，仍不能自由摆放。其余决定不变。
- 需要补充家具与软装素材（款式、灯具、地毯、挂画等，按风格成套），并让家具布局支持多楼层别墅与房间类型。
- Agent 工具合约需要扩展铺贴、软装风格与多楼层布局；工作台需要配置真实模型（`HESTIA_MODEL_*`），企业额度按 ADR-0007 的工作空间用量规则。
- 现有客户端与演示数据的“石材企业”文案改为家装企业；已完成工单的历史记录不改。
