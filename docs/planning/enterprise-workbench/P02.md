## Problem Statement

企业工作台界面还没有设计，实现前需要先确认页面、信息层级与操作流程。

## Solution

交付电脑端可点击交互原型，使用演示数据，不接服务端；视觉依据 B 版（家居杂志）。文案按 ADR-0008 使用“一站式家装企业”。

## User Stories

1. As a 产品负责人, I want 在浏览器里点完成员的主要流程, so that 判断页面和流程是否合适。
2. As a 产品负责人, I want 看到各类状态与空状态, so that 实现时不遗漏。

## Implementation Decisions

- 页面：登录；企业工作台首页（今日需处理：待审核、请求联系、待批准绑定）；线索列表（筛选、状态）；线索详情（客户、需求、方案效果图对比、确认与留言、跟进状态与备注、分享与绑定记录）；审核发布（待审方案、排版提示、发布）；辅助转换（导入户型说明）；预置方案（选饰面与石材）；分享（定向手机号 / 绑定码、链接与绑定码只显示一次）；审批绑定申请；撤销与解绑确认；石材库与软装风格目录；**Agent 出方案**（在线索或预置方案中对话，候选方案含硬装与软装，核对后采用为待审方案）；方案详情中区分硬装与软装。
- 1440×900 为主，兼顾 1280 与 1024；B 版视觉：暖纸背景、褐墨、酒红强调、细分隔线、左叙事栏 + 右大幅画面、底部条目栏，仓耳渔阳体。
- 放在 `example/prototypes/enterprise-workbench/`，源码在 `src/`，构建为离线单文件；原型审阅导航可直达各页面与状态，不属于产品界面。
- 演示数据中性命名，标注示意，不含真实企业资料。

## Testing Decisions

- [ ] 浏览器 1440 / 1280 / 1024 宽逐页截图自查，独立视觉复核。
- [ ] 用户审阅通过并明确同意后，界面工单才可开始。

## Out of Scope

接服务端；手机端适配。
