# 项目现状与决策时间线

本文件记录 Hestia 的当前范围、已确认决策和工单进度。规则见根目录 `AGENTS.md`；决定正文以 `docs/decisions/` 为准，验收证据以 `docs/validation/` 和 [工单映射](planning/v1-published-issues.json) 为准。未验收的工单不得当作已完成。

## 当前范围（以最新为准）

- **定位（2026-10-28）**：Hestia 是共享内核，服务个人与企业两种工作空间；企业场景以石材硬装饰面铺贴为重心，先做 H5 可行性演示，小程序确认后以 web-view 内嵌，见 `decisions/0007-shared-core-personal-and-enterprise-workspaces.md`。T02、T11–T14、T18、T22–T24 与 C02 按该决定暂停，未关闭。
- **注册与积分（2026-10-25）**：取消邀请制限制，开放注册，以简单积分控制免费使用，首期无付费功能，保留订阅扩展能力。游客只看公开示例；注册登录后一次性领取积分。不做匿名账号/积分、匿名身份升级、游客项目转移、积分叠加或账号合并，见 `decisions/0006-open-registration-free-credits.md`。问答 1 分／小改 5 分／整套设计 20 分及赠送 40 分为试用占位，后续按供应商真实用量反推调整。C01（游客示例、注册、一次性赠送）已本地验收；C02（AI 任务积分扣退）未实施。
- **视觉方向（2026-10-25）**：生产 UI 只采用家居杂志（editorial）；建筑展馆仅保留为原型历史。原型由用户移入 `example/prototypes/projects`，保留该目录。
- **模型（2026-10-25）**：C 端首版仅平台模型，不提供 BYOK/自定义端点，见 `decisions/0002-agent-led-consumer-workflow.md`。旧规划中的浏览器自接模型是历史基线。具体供应商与部署未定。
- **用户与运维**：大陆用户优先、无需代理；主要由用户和 AI 维护，低成本、少运维、托管优先并保留迁移能力，预算未定，见 `decisions/0004-mainland-invited-pilot-managed-services.md`（其中邀请制上线范围已被 0006 覆盖）。
- **对话与运行时**：统一对话入口，同一轮允许问答与设计修改并存；模型调用统一在 Worker，流式回复，关页不取消已接受轮次，见 `decisions/0005-unified-conversation-entry.md`。实现采用 AI SDK Core + pg-boss + Hestia 专用有限状态运行器、独立领域执行器及 SSE 持久化事件。
- **Agent 设计任务**：候选阶段连续推进，不逐个工具确认；采用初始空间或整套方案时确认，明确局部修改可直接应用并撤销，固定事实变更单独处理。工具与 prompt 草案见 `agent/tool-contract.md`、`agent/system-prompt.md`。
- **首版流程**：单层图纸 → 设计 → 迭代 → 3D/静态图；room tour 后续扩展。缺尺寸可继续概念设计，确认尺度或判断可放置前须补可靠尺寸。关页后任务在平台上限内继续，可恢复、取消，见 `agent/runtime-design.md`；完整后台运行链路未验收。
- **模型策略**：复杂设计优先质量、局部修改优先速度，共用执行约束，见 `agent/model-policy.md`；具体模型与预算须业务样本验证，不要求用户凭型号选择。
- **架构基线**：`web-stack.md` 与 `decisions/0003-modular-monolith-with-durable-workers.md` 已确认，作为首版实施基线；精确版本、模型能力、渲染及恢复仍需验证，部署方案不在定稿范围。
