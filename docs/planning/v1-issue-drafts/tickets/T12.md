## Acceptance criteria

- [ ] 墙端点、开口及相关字段校正经同一领域命令，2D/3D 同步。
- [ ] 凹形、斜墙、无效轮廓与越界开口的错误能定位；缺检查不声明通过。
- [ ] 修改仅限未确认初稿，不能借此更改已确认建筑。
- [ ] 纠正可恢复且持久化，不以开发者编辑 JSON/数据库代替产品入口。
