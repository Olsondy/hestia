## Problem Statement

私有文件（图纸、效果图）的存储键不带企业，无法按企业清点；也没有办法在企业停止合作或要求迁出时交付或删除它的全部数据。

## Solution

私有文件键以工作空间开头；提供导出与删除一家企业全部数据的维护命令。

## User Stories

1. As a 维护者, I want 导出一家企业的全部数据与文件, so that 企业迁出时能完整交付。
2. As a 维护者, I want 删除一家企业的全部数据与文件, so that 合作结束后不留存客户资料。
3. As an 企业成员, I want 其他企业的文件地址在我这里打不开, so that 文件不外泄。

## Implementation Decisions

- 新文件键形如 `{workspaceId}/…`；已有文件由迁移命令移动并更新引用，可重复执行。文件读取继续经访问检查，不提供长期公开地址。
- `pnpm workspace:export <slug> <dir>`：导出该企业的工作空间、账号、项目、方案、线索、目录、事件与文件，JSON 加原文件，附清单与校验和；不含其他企业的数据，不含密钥与会话。
- `pnpm workspace:delete <slug> --confirm <slug>`：删除数据库数据与文件，输出删除计数；进行中的后台任务先取消。
- 两条命令只供维护者在服务端执行，不提供接口。

## Testing Decisions

- [x] PostgreSQL + 本地文件存储：导出包含 A 的全部记录与文件且不含 B；删除 A 后 A 的记录与文件为零、B 不变；文件键迁移可重复执行且引用正确；B 的成员读取 A 的文件被拒。

见 [M04 验证](../../validation/M04-workspace-data.md)。

## Out of Scope

把导出包导入另一套部署；对象存储供应商接入；定期备份策略。
