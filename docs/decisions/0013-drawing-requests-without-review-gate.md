# 图纸需求不设企业审核门槛；DXF 实时出方案，图片排队处理

D05/D06 的实现比 ADR-0007 更严：DXF 转换成功后一律进入“待审核”，要等企业成员发布，才开始生成方案。用户于 2026-11-03 指出，这不应该是硬性门槛：转换不了是图纸本身的问题，在客户端直接告诉客户即可。本决定覆盖 D06 中“图纸需求转换后待审核”的部分，以及 S01 原来“先生成待审方案、再由成员发布”的设计。

## 决定

- **统一上传入口**：DXF、图片（JPG / PNG）、PDF 和 DWG 都从同一处上传。
- **DXF 实时出方案**：后台转换成功、空间候选通过校验后，自动采用为项目空间，派生地面与楼梯饰面，按规则生成方案并出图，与示例别墅一样直接发布给客户，不经企业审核。
- **DXF 转换不了**：客户端直接说明原因（例如没找到闭合墙线、单位无法确定），并提示从 CAD 重新导出的方法；客户可以重新上传，或选择“交给企业整理”。
- **图片、PDF 与 DWG 排队处理**：不做实时识别，提交后在「我的项目」显示“排队处理中”，像下单一样；由企业成员整理户型后出方案（W03 辅助转换）。这一路不调用任何模型。
- **没有待审**：通过排版校验的方案直接发布（不通过的方案不给客户）；一个都不通过时，与转换失败一样直接告诉客户原因，可重新上传或交给企业整理。唯一的例外是企业主动开启的“全部审核后发布”（默认关闭，界面无入口）。
- **免费次数**：只对登录客户开放上传，每位客户在每家企业每天 3 次（按北京时间自然日计），转换失败也计入；企业可在工作空间设置 `drawingUploadsPerDay` 调整。
- **不调用生成式 AI**：DXF 转换、方案生成和出图都是确定的程序与规则。照片、PDF 自动识别若以后要做，另立调研，先用真实样本验证准确率和合规要求（含是否涉及生成式 AI 服务备案或登记）。

## 影响

- 转换 Worker 在 DXF 转换完成后，接着为对应需求生成方案（需要出图队列）。
- 需求状态增加 `conversion_failed`（客户可见原因，可重新上传或交给企业整理）；`assisted_conversion` 在客户端显示为“排队处理中”。上传图纸受每日次数限制。
- 成员“发布”接口保留，只用于开启了“全部审核”的企业；辅助转换（W03）完成后同样直接出方案。
- S01 改为本决定的实现；W03 只处理排队的图片、PDF 与客户主动交给企业的图纸。

## 考虑过的替代方案

- **维持 DXF 一律待审**：最稳，但客户每份 DXF 都要等企业，企业也会成为瓶颈；用户明确不要。
- **转换失败自动转企业处理**：客户不用操作，但很多失败只是导出方式不对，客户自己重新导出更快；所以失败先告诉客户，交给企业由客户选择。
