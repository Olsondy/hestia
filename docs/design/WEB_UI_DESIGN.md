# Web 工作台 UI 设计规则

企业工作台（电脑端，成员使用）的界面规则，以 [界面工程准则](ENGINEERING_RULES.md) 为底线，只在其上收紧。与 H5 客户端同属柔和中性家族（[ADR-0011](../decisions/0011-unified-soft-neutral-for-enterprise.md)），共用配色与字体，版式按电脑端单独设计。手机端规则见 [H5_UI_DESIGN.md](H5_UI_DESIGN.md)。

视觉方向由用户于 2026-11-03 在风格对比稿 `example/prototypes/enterprise-workbench-styles` 中选定 **B 悬浮**，实现依据为 `example/prototypes/enterprise-workbench/src/`（P02 原型，同日经用户审阅定稿）。

## 定位

- **模式**：Operate。成员一天里反复扫读线索、核对方案、回电、分享，效率与可扫读性优先于表现力；品牌只体现在精确的细节里。
- **不是杂志**：不用展示衬线、超大标题、标题上方眉标、奶油纸底与满屏分隔线（准则 T4、T9、L6）。旧版家居杂志原型只作历史参考。
- **两套主题**：浅色与深色都必须提供，默认跟随系统，可在个人菜单中切换。两套主题共用同一组语义 token，组件里不写字面色值；每个界面都要在两套主题下验收。

## 布局

- **视口**：以 1440 × 900 为主，兼顾 1280 与 1024（平板横屏）；最小宽度 1024。
- **页头**：一行，包含企业标识、主导航（今日、线索、预置方案、石材与软装）、全局搜索、成员菜单。不放说明性文字。
- **列表类页面**（今日、线索、石材与软装）：内容区居中，最大宽度约 1240px；页面标题用页面级字号，一页一个，不加眉标。筛选在标题下方一行，列表在一整块表面里，行与行靠间距和悬停底色区分，不逐行画线。
- **方案工作台**（线索详情里的方案部分）：以效果图 / 3D 画面为中心，铺满页头以下的空间。方案信息（方案列表、硬装与软装、客户与跟进、分享）在一侧面板，Agent 助手在另一侧面板，二者都可以收起；画面相关的控制（楼层、效果图 / 3D、面板开关）集中在一条工具条上。画面不得被分隔线切成格子。
- **窄屏**（≤ 1180px）：两侧面板一次只开一侧，打开一侧时自动收起另一侧，保证画面可见；面板略变窄，页头隐藏成员姓名。

## 组件规则

- **按钮**：主按钮一种样式，文字居中，不带箭头；每个区域最多一个主按钮。危险操作（撤销分享码、解绑、拒绝）用描边加危险色文字，且必须二次确认。
- **状态**：线索与方案状态用中性底的文字标签，只有「需要成员处理」的状态（请求联系、待审核、待批准绑定）用强调色；不使用红黄绿同时亮（准则 C4、C5）。
- **候选与待审**：Agent 的候选方案、成员未发布的待审方案必须在方案列表、画面标题处同时标明「客户不可见」；采用、发布都需要确认。
- **Agent 助手**：是辅助，不是页面。它基于当前选中的方案工作，结果以候选进入同一块画面与方案列表；对话、进度、快捷提示都在面板内。未配置模型或网络不可用时如实说明，并提供「打开预先出好的演示方案」，不模拟结果。
- **一次性信息**：分享码与分享口令只显示一次（ADR-0012），弹层里提供「复制分享口令」并明确提示「关闭后不能再查看」。分享码用等宽字体（准则 T8 允许的用途）。
- **数字**：手机号、金额、尺寸、修订号、计数一律 `tabular-nums`；成员可见完整手机号，其余场景脱敏。
- **表面与层级**：一个区域一层表面，面板内不再套有底色的卡片（准则 L4）；面板与画面之间的层次用一层克制阴影或一条细边框，二选一（准则 K5）。不用毛玻璃（准则 K4）。
- **键盘**：所有操作可用键盘完成，焦点可见；弹层用原生 `dialog`，Esc 关闭并把焦点还给触发元素。

## 视觉方向：B 悬浮

画面铺满页头以下的区域，方案面板与 Agent 助手是浮在画面上的**实心**圆角面板（不用毛玻璃），画面标签与工具条是同样材质的胶囊。列表类页面沿用同一套面板：一块实心表面、柔和阴影、内部靠留白分组。

### Token

全部定义在 `style.css` 的 `:root`；深色主题在 `prefers-color-scheme: dark` 与 `[data-theme=dark]` 下覆盖同名变量。组件里不写字面色值。

| 组别 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--c-bg` | #f2f1ee | #121214 | 页面底、页头 |
| `--c-surface` | #fff | #1b1b1e | 面板、表格、输入框 |
| `--c-surface-2` / `-3` | #ebe8e2 / #dfdbd3 | #26262a / #323237 | 选中行、分段控件底、标签底 / 更深的填充 |
| `--c-canvas` | #e6e3dd | #0c0c0e | 方案画面的底色 |
| `--c-ink` / `--c-ink-2` | #161514 / #5f5b54 | #f1f0ec / #9d9a93 | 主文字 / 次要文字 |
| `--c-line` / `--c-line-strong` | #e2ded6 / #c9c3b8 | #2c2c30 / #45454b | 面板内少量分隔 / 控件描边 |
| `--c-primary` | #161514 | #f1f0ec | 主按钮、选中的筛选、Agent 开关 |
| `--c-accent`（陶土） | #9a5b3f | #e0a184 | 只用于需要成员处理的状态、候选标记、计数 |
| `--c-danger` | #a23a26 | #f0937e | 只用于危险操作的文字与冲突图标 |

- **字体**：仓耳渔阳体 400 / 500。页面标题 28 / 面板与弹层标题 20 / 小节标题 15 / 正文 14 / 辅助 12（相邻级差 ≥ 1.17，标签靠字重区分，不新增字号）。数字一律 `tabular-nums`。
- **圆角**：8（标签、缩略图、输入框）· 12（列表行、提示）· 16（面板、弹层）· 胶囊（按钮、分段控件、工具条、画面标签）。
- **层级**：面板与浮层用同一层阴影（浅色 `0 1px 2px #0000000f, 0 6px 20px #00000014`），弹层略重；不用描边加大阴影（准则 K5）。
- **动效**：150ms（状态变化）/ 240ms（面板出现、弹层），缓动 `cubic-bezier(.16,1,.3,1)`；只过渡背景、颜色、透明度与位移；`prefers-reduced-motion` 下取消。
- **主题切换**：页头的太阳 / 月亮按钮在浅色与深色之间切换，默认跟随系统。

### 组件对照

| 类名 | React 组件（建议） | 要点 |
| --- | --- | --- |
| `.topbar` `.topnav` | `TopBar` | 导航为胶囊，当前项填充 `--c-surface-2`；「今日」计数用强调色 |
| `.btn` `--primary` `--secondary` `--danger` `--sm` | `Button` | 文字居中、不带箭头；危险操作二次确认 |
| `.tag` `--act` | `StatusTag` | 中性底 + 文字；`--act` 为强调色文字加小圆点 |
| `.note` `--hint` `--danger` `--ok` | `Note` | 中性底，标题加粗写明性质，只给图标上色 |
| `.hint-line` | `HintLine` | 卡片内的提示行，不带底色（准则 L4） |
| `.segmented` `--wrap` `--bare` | `Segmented` | 互斥切换；`--bare` 用在工具条里 |
| `.chip` | `FilterChip` | 跟进筛选、有效期 |
| `.panel` | `Panel` | 列表页的唯一表面层 |
| `.canvas` `.stage` `.caption` `.toolbar` | `SchemeCanvas` | 画面铺满；标签与工具条跟随可见区域居中 |
| `.float--left` | `SchemePanel` | 页签：方案 / 客户与跟进 / 分享与绑定；底部放当前状态的主操作 |
| `.float--right` | `AgentPanel` | 对话、分步进度、快捷提示、输入框；候选进入同一画面 |
| `.scheme` `--cand` | `SchemeItem` | 缩略图 + 名称 + 状态；候选缩略图虚线强调色描边 |
| `.table` `.table__row` | `LeadTable` | 行靠间距与悬停底色区分，不逐行画线 |
| `.quick__item` | `QuickFilter` | 三个需要处理的入口，点击即筛选 |
| `.action-bar` | `ActionBar` | 审核、辅助转换、预置方案页底部悬浮的操作条 |
| `.steps-row` | `StepList` | 审核与转换的进度 |
| `dialog.modal` | `Modal` | 原生 `dialog`，打开后焦点在弹层上 |
| `.proto-btn` | 不实现 | 原型审阅入口 |

## 验证

- 每个页面在 1440、1280、1024 三个宽度，浅色与深色两套主题下截图检查。
- 方案工作台需实际操作：切换方案、楼层、效果图 / 3D，开关两侧面板，跑一遍 Agent 候选 → 采用 → 发布。
- 对照 [界面工程准则](ENGINEERING_RULES.md) 逐节自查后再提交审阅。
