# H01 H5 客户端验证

日期：2026-11-03。范围：工单 #39。本机 PostgreSQL 14（独立库 `hestia_h01`）、Next.js dev（127.0.0.1:3101）、出图 Worker；短信为模拟发送。浏览器验收使用 Playwright Chromium，手机视口 390×844、2 倍像素、触屏。

## 实现要点

- **路由**：企业入口 `/c/{entry}`（首页、`/login`、`/new`、`/projects`、`/r/{requestId}` 及 `/adjust`、`/confirm`、`/done`），分享链接 `/s/{token}`（预览）与 `/s/{token}/bind`（绑定、`?apply=1` 申请）。客户端使用独立的根布局与样式（`app/(client)`），工作台移到路由组 `app/(workbench)`，路径不变。页面只调用公开 HTTP 接口。
- **依据原型**：版式、文案、状态与 P01 一致。与原型不同、按服务端真实规则实现的地方：
  - 上传图纸：原型在提交前显示“自动转换中 → 已转换”；实际为提交后在后台转换，进度显示在方案需求页（转换中 → 待审核 / 需辅助转换）。图纸需求不能在提交前勾选具体饰面，只选“地面 / 背景墙 / 楼梯踏面”范围，写入需求说明。
  - 调整：原型先攒多处修改再“重新出图”；实际每次点选即提交一次修改，服务端排版校验，通过即生成新修订并后台出图，不通过显示“冲突 · 不能出图”且方案不变。撤回回到上一修订并复用其效果图。
  - 未选石材时，按企业石材库的前 3 款出方案（服务端要求至少 1 款）。
  - 色调、铺法、波打线偏好作为需求的 `preferences` 保存（迁移 0029），供企业跟进；规则生成不读取偏好。
  - 分享预览横幅显示“企业分享给你的方案”，服务端不对外提供成员姓名。
- **3D**：`SchemeViewer` 复用 `scene-runtime`（手机默认 medium 画质）和预设镜头，场景为该方案当前效果图的冻结快照（新增 `GET /api/client/{entry}/requests/{id}/schemes/{schemeId}/scene` 与 `GET /api/share/{token}/schemes/{schemeId}/scene`），界面注明“实时 3D · 以效果图为准”。
- **效果图镜头**：方案出图改用室内人视角预设镜头（铺贴饰面最多的楼层的主要房间），画质仍为 ultra。软件渲染下室内 ultra 单张约 100 秒（鸟瞰约 50 秒、室内 high 约 45 秒，high 有阴影锯齿），出图租约由 120 秒改为 360 秒、队列过期由 180 秒改为 420 秒，避免仍在渲染的任务被判中断重试。
- **服务端补充**：方案需求视图增加 `title`、`origin`、`drawingName`、`finishes`（名称、类型、楼层）与 `preferences`；目录增加示例别墅平面（房间、墙、楼梯轮廓）；分享预览对已登录访客返回 `viewer`（是否已绑定给自己、申请状态），失效链接返回原因（撤销 / 过期）；`/api/session` 返回登录手机号用于脱敏显示。
- **刷新恢复**：服务端状态（需求、方案、修订、确认、绑定）刷新后从接口恢复；提交向导草稿存 localStorage（关页后仍在，图纸文件需重新选择）；方案选择、楼层、调整记录、确认留言草稿存 sessionStorage。所有写操作带 `operationId`，重试不重复。
- **出图稳定性**：渲染页的加载与就绪等待由 90 秒改为 150 秒（截图 45 秒），在 360 秒租约内；此前室内 ultra 在本机同时运行浏览器 3D 时会超时并耗尽重试。调整后整轮验收中已完成的 7 张效果图全部一次成功（验收结束时另有 3 张仍在排队或出图）。
- **修复**：认证路由在 Next 服务器下用 `new Request(request, …)` 复制请求会抛 TypeError（集成测试直接调用路由函数，未覆盖到），手机验证码与邮箱登录在真实服务器上都会失败；改为按 URL 重建请求。`instrumentation.ts` 的 Node 专用检查移到 `instrumentation-node.ts`，Edge 编译不再报错。
- 首页封面 `public/client/demo-villa-cover.jpg` 由示例别墅与演示铺贴方案经后台同一渲染管线生成（示意素材）。

| 检查 | 结果 |
| --- | --- |
| `pnpm check` | 通过，核心测试 95 项 |
| `pnpm test:db` | 153/154；唯一失败为本机未配置真实模型的准入测试，与本票无关 |

本票新增的接口断言：分享场景快照可公开读取、伪造令牌 404；未登录读取客户场景 401、非绑定客户 404、绑定客户 200；预览对未登录访客无 `viewer`，对陌生客户为未绑定、无申请，对待批准与被拒申请人分别返回 pending / rejected，对已绑定客户返回 boundToMe；撤销后的链接返回原因 `revoked`；客户提交的偏好随需求保存。
