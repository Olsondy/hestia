## Problem Statement

演示需要企业工作台里有处于不同状态的线索，并能与客户端一起完整演示。

## Solution

扩展 `pnpm demo:seed` 准备工作台演示数据，补充演示说明，并完成工作台与客户端的联合验收。

## User Stories

1. As a 演示者, I want 一条命令准备好两端的演示数据, so that 现场快速复位。
2. As a 演示者, I want 一份讲解顺序, so that 先讲客户端再讲企业如何跟进。

## Implementation Decisions

- 种子经服务接口准备：客户自助已确认并请求联系、DXF 待审核、需辅助转换、待批准的绑定申请、已有跟进备注的线索；演示成员设置本地演示密码并在输出中显示。
- 演示说明合并到 `docs/demo/stone-h5-demo.md`。

## Testing Decisions

- [ ] 真实浏览器：工作台与客户端联合流程，拦截外网请求；种子重复执行幂等、重置后可再次演示。

## Out of Scope

生产部署。
