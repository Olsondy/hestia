# H5 客户端交互原型（P01）

供产品负责人审阅交互与视觉的手机优先原型：纯前端、演示 fixture、不接服务端。**只用于审阅，不作为生产实现的代码基础。** 对应工单 #38（总规格 #29，ADR-0007）。

## 打开

- 直接用浏览器打开 `index.html`（离线单文件，内嵌脚本、样式、Three.js 和仓耳渔阳体 400/500 两档；无网络请求）。建议用手机或浏览器设备模拟（390×844、360×780）。
- 源码在 `src/`，不要直接改生成的 `index.html`。从仓库根运行 `pnpm build`（或 `node scripts/build-client-h5.mjs`）重新生成。
- 页脚或页头的「演示」进入**原型审阅导航**：可直接跳到任一页面和状态（跳转会重置演示数据）。该入口不属于产品界面。
- 状态存于浏览器 localStorage（键 `hestia.client-h5.v1`），审阅导航底部可清空。

## 示意素材

- 石材贴图（雅士白、鱼肚白、莎安娜米黄、灰木纹、啡网纹、黑金花）由 `src/stone.js` 用值噪声程序生成，不是照片、不是企业素材，没有使用外部贴图；石材名为行业通用品类名。界面统一标注「示意素材」。
- 效果图与 3D 由 `src/render3d.js` 在浏览器内用 Three.js（MIT，许可证随构建内嵌）实时渲染的简化场景，家具仅为氛围体块。
- 中文字体为仓耳渔阳体，来自 `assets/fonts/tsanger-yuyang/`，许可声明 `NOTICE.txt` 随构建内嵌。
