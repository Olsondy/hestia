## Problem Statement

成员需要在界面上为客户预置方案并分享，处理绑定申请、撤销与解绑。

## Solution

实现预置方案、分享（定向手机号 / 绑定码）、审批绑定申请、撤销链接、解绑客户与操作记录。

## User Stories

1. As an 企业成员, I want 选饰面和石材为客户预置示例别墅方案, so that 先发方案给客户。
2. As an 企业成员, I want 创建分享后立即复制链接与绑定码, so that 另行告知客户。
3. As an 企业成员, I want 批准或拒绝绑定申请、撤销链接、解绑客户, so that 处理发错与冒认。

## Implementation Decisions

- 按获批原型实现，复用 D08 接口；链接与绑定码只在创建时显示一次，关闭后不可再查看，界面明确提示。
- 撤销、解绑、拒绝需要二次确认；操作记录按时间显示在线索详情。

## Testing Decisions

- [ ] 真实浏览器：预置方案 → 定向分享 → 客户端用该手机号绑定 → 成员看到绑定记录；绑定码分享 → 客户输码绑定；申请 → 批准；撤销后链接失效。

## Out of Scope

协作者邀请；成员代客户调整方案。
