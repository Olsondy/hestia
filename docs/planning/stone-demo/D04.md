## Problem Statement

现有领域只能给家具换材质，无法表达地面、墙面、楼梯踏面上的石材铺贴，也不能校验排版。

## Solution

新增饰面领域对象与铺贴方案，排版引擎计算整块与切块并校验；渲染器按排版显示石材；提供工作空间私有的示意石材目录。

## User Stories

1. As a 客户, I want 地面、背景墙、楼梯踏面分别铺不同石材, so that 看到真实组合效果。
2. As a 客户, I want 选择规格和铺法（直铺、工字、人字、斜铺）, so that 比较排版差异。
3. As a 客户, I want 加一圈波打线, so that 看到高端铺装效果。
4. As an 企业成员, I want 排版出现过窄切块时得到提示, so that 方案可以施工。
5. As a 维护者, I want 示意石材标注来源与许可, so that 演示素材合规。

## Implementation Decisions

- 饰面属于固定事实：地面区域（可由房间轮廓派生或单独划分）、墙面（墙的某一侧及范围，扣除门窗洞）、楼梯踏面。家具移动或候选切换不影响饰面几何。
- 铺贴方案引用目录石材 ID 与版本，记录规格、铺法、缝宽、起铺点（居中或靠边）、方向，以及可选波打线（宽度与石材）。铺贴修改为候选命令，进入现有候选、校验、采用与撤销链路，不复用家具材质替换。
- 排版引擎为纯 TypeScript：输出整块与切块的几何和数量；校验窄条（阈值可配置）、超出饰面、目录项缺失或版本失效，区分硬冲突与提示。
- 渲染：按排版生成石材贴图映射与缝线，抛光/哑光以材质参数区分；交互与后台出图一致。
- 目录：工作空间私有石材目录（名称、贴图、规格范围、表面类型）。演示使用 CC0 示意贴图，记录来源与许可，界面标注“示意素材”。
- 词汇遵循 CONTEXT.md 的“饰面”“铺贴方案”，铺贴方案必须改变石材、规格、铺法或排版。

## Testing Decisions

- [ ] 排版夹具：矩形与凹形地面、带门洞墙面、楼梯踏面，各铺法的整块/切块数量与窄条判定。
- [ ] 候选链路：铺贴修改可校验、采用、撤销；锁定饰面与固定事实不被改动；目录版本失效被拒绝。
- [ ] 同一方案交互与后台出图一致，人工核对缝线与方向。

## Out of Scope

连纹/对纹、拼花图案库、台面、用料估算与报价、企业真实素材。
