## Problem Statement

成员无法选择模型；对话运行时只认环境变量里的一个模型与代码内指纹。

## Solution

Agent 交互处列出本企业已启用的模型供选择；任务绑定所选模型；运行时从模型登记读取已准入模型，不再读取 `HESTIA_MODEL_*`。

## User Stories

1. As an 企业成员, I want 在对话框旁选择模型, so that 按任务取舍速度与质量。
2. As an 企业成员, I want 中途换模型只影响之后的步骤, so that 已完成的结果不被重做。

## Implementation Decisions

- 接口返回本企业已启用模型的显示名称与说明（不含地址、密钥、单价）与额度状态；可复用的模型选择组件供 W07 使用。
- 任务记录模型登记与版本；切换从下一次调用起生效；所选模型停用、准入失效或供应商故障时停止并提示改选，不自动换用。
- 运行时改从模型登记取模型并经 AM03 预占、AM04 记录；删除 `PLATFORM_ADMISSION` 指纹路径与运行时对 `HESTIA_MODEL_*` 的读取，改写依赖它的准入测试。

## Testing Decisions
