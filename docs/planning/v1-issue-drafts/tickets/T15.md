## Acceptance criteria

- [ ] 目录提供稳定资产/材质 ID、可用尺寸范围和版本，不能编造资源。
- [ ] 增删替换先写候选，具体差异可见，替换/删除按成果确认后提交。
- [ ] 目录参数和组合经过几何检查，不能缩小已测实物来消除冲突。
- [ ] 固定事实不能通过删除重加绕过，采用后可撤销且保持目录版本可追溯。
