# 采用 TypeScript 模块化单体，将持久化设计与渲染任务放入独立 Worker

Hestia 已确认平台模型、关页后继续以及候选/正式方案分离。采用 Next.js 承载 Web 与请求 API，独立 Node.js Worker 执行设计和渲染；共享领域代码、PostgreSQL 及版本化契约，以减少浏览器、模型和后台之间的数据与规则重复。用户于 2026-10-25 审阅技术文档后确认本实现架构定稿；具体版本与能力须验证，部署方案另议，功能开发仍暂停。

## 已接受决策

- 采用 TypeScript 模块化单体，使用 pnpm workspace 管理 Web、Worker 和必要共享模块。代码包的拆分不改变单一 Hestia 领域上下文，不要求新增业务微服务。
- Web 使用 Next.js App Router / React，提供 HTTP JSON API 与可恢复的 SSE 任务事件；统一对话入口允许同轮问答与修改，所有模型调用在 Worker 中执行，普通问答走短执行路径，Next 请求不持有模型或设计任务生命周期。
- PostgreSQL 保存项目、候选、固定事实、修订、采用事件、操作结果、任务和用量；Drizzle 管理数据访问与迁移，关键提交通过同一事务和版本检查实现。
- pg-boss 使用同一 PostgreSQL 调度后台任务，优先验证事务入队集成；不通过时使用同事务待调度记录投递。业务任务状态、执行代次、幂等和取消仍由 Hestia 负责，不把队列语义等同模型调用或设计变更 exactly-once。
- AI SDK Core 负责供应商协议和结构化工具调用；Hestia 专用有限状态运行器负责阶段、预算、授权与恢复，领域执行器独立负责最终修改。通用调度与重试使用 pg-boss，不自写通用队列或工作流框架；首版不引入额外图编排框架或多主 Agent。
- 交互 3D 优先复用 Three.js，通过独立场景适配器读取领域数据；React 只管理挂载与交互。2D 使用 Konva 做最小校正；后台 Playwright Chromium 复用同一场景模块生成静态图，运行效果仍需验证。
- Better Auth 接入邀请制邮箱密码身份，业务服务执行资源归属检查；私有对象存储承载图纸及成果，优先标准 S3 API，厂商专有接口由文件适配层隔离。Docker Compose 用于本地联调。Agent 与 Render 保持独立入口和队列；[ADR-0004](0004-mainland-invited-pilot-managed-services.md) 的低成本、少运维偏好保留，具体生产部署、实例拓扑和云厂商不在本轮确认范围。

具体组件表、调用边界、官方依据及兼容性待验项见 [Web 技术栈](../web-stack.md)。选择技术方向不代表版本已安装、集成已通过，也不恢复功能开发。

## 考虑过的替代方案

- **浏览器运行 Agent**：无法满足关闭页面后继续及平台长期凭据边界，已被 ADR-0002 的产品决定排除。
- **纯前端 Vite + 独立 API 框架**：可行，但当前没有独立公共 API 的需求；采用 Next 将页面、会话和请求入口集中，领域与 Worker 保持框架无关，保留后续拆出 API 的余地。
- **全部运行在 Next 请求中**：组件少，但任务恢复、长调用、渲染资源及请求生命周期耦合；采用独立 Worker。
- **Redis/BullMQ 或独立工作流平台**：提供另一种队列/流程运行选择；首版先用已有 PostgreSQL 减少系统数量，通过真实故障与负载验证是否足够。
- **LangGraph 持久化编排**：可承担图状态检查点，仍需明确其与项目事务、确认及操作记录的关系。当前有限状态设计先采用应用运行器；如果恢复和分支逻辑的维护成本超出预期，应重新比较，不无限扩展自建通用框架。
- **全量重写成 R3F 或直接嵌入外部设计器 HTML**：前者提前放大展示迁移，后者尚无验证过的稳定状态接口；先定义场景适配器并验证现有 Three.js 通用化。

## 影响

- Web 与 Worker 可以独立限流和重启，仍共享一套事实与命令契约；需要维护少量跨进程入口和数据库迁移兼容。
- 同库队列减少基础设施，但任务负载与项目查询共享数据库，需要观察连接池、锁等待、任务积压及清理策略。
- 不使用持久化 Agent 框架意味着必须直接验证检查点、租约、旧结果拒绝和预算累计，不能仅依赖 SDK 的工具循环。
- 渲染 Worker 需要额外浏览器运行环境；服务器 WebGL 与交互画布的一致性是 T03/T20 的退出门槛，不能仅靠截图 API 存在就判定可用。
- 这项决定替代旧技术文档中的浏览器 BYOK、完整编辑器优先和浏览器关闭即中断的技术基线；不改变 ADR-0001/0002 的产品决定。
