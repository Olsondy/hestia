# 固定事实独立于家具布局方案

用户确认原有整排固定柜不可移动、空调位置固定后，我们把门窗、柱位、楼梯、固定柜、空调、电视墙等已确认设施建模为独立于布局方案的固定事实：三套布局只能调整可移动家具，固定事实从不进入布局的摆放表（`src/sample/layouts.js`），工作台中也会锁定并拒绝编辑（`src/store.js` 的 `fixedIds`）。另一种做法是把所有物品统一放进各方案的摆放表，这样实现更简单，但切换方案或风格时可能悄悄挪动用户确认过的事实，因此没有采用。

## Consequences

- 新增已确认设施时，必须同时加入 `fixedIds` 并保持不出现在布局摆放表中，否则会被方案切换或用户拖拽移动。
- 共享材质改色时要避免波及固定物品（见 `AGENTS.md`），否则会出现「只换色却影响了固定事实」的错觉。
