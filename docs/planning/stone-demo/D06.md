## Problem Statement

客户需要在手机上自己提交需求并得到铺贴效果，企业需要由此得到线索；结果不可靠时不能直接展示。

## Solution

服务端：客户登录后以示例别墅或上传图纸，选择空间与石材，后台按规则生成 2–3 个铺贴方案并出图；不可靠结果进入待审核，成员经接口审核发布。

## User Stories

1. As a 客户, I want 选择示例别墅或上传图纸开始, so that 有无图纸都能体验。
2. As a 客户, I want 选择要铺石材的空间和喜欢的石材, so that 方案符合我的偏好。
3. As a 客户, I want 得到 2–3 个有差异的方案效果图并查看 3D, so that 能比较。
4. As a 客户, I want 看到“等待企业审核”状态和进度, so that 知道何时有结果。
5. As an 企业成员, I want 客户提交自动成为线索, and 审核发布待审核项目, so that 及时跟进。

## Implementation Decisions

- 方案需求记录图纸来源、所选空间与石材偏好，归属客户与工作空间，形成线索。
- 方案生成为确定性规则：按空间类型与尺寸选择规格与铺法组合，产出 2–3 个满足“铺贴方案必须有差异”的候选，经 D04 校验后后台出图。不调用生成式 AI。
- 校验不通过或工作空间配置要求审核时进入待审核；成员接口可修改并发布。客户只能看到已发布方案。
- 本票交付服务端接口与后台任务，页面在 H5 实现中完成。关页后任务继续，重开可查询进度。

## Testing Decisions

- [ ] 示例别墅与 DXF 两种来源都能生成 2–3 个有差异的已校验方案并出图。
- [ ] 校验失败与“全部审核”配置下进入待审核；成员发布后客户可见；未发布不可见。
- [ ] 线索记录可由成员接口查询；客户之间互相不可见。
- [ ] 经 HTTP 接口完成提交到查看已发布方案，任务中断后可查询并继续。

## Out of Scope

成员审核界面、对话式需求、Agent 生成方案、用料估算。
