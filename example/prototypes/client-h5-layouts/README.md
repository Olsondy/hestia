# H5 客户端布局探索稿

在风格探索稿（`../client-h5-styles`）之后，比较三种不同的页面组织方式。配色统一为同一套中性色，每种布局都有浅色与深色两种主题。

- 直接用浏览器打开 `index.html`（离线单文件）。顶部切换页面（首页 / 方案 / 调整 / 确认）与主题（浅色 / 深色 / 浅深并排）。
- 页内可操作：① 在效果图上左右滑动或点箭头切换方案、点抽屉把手展开详情；② 点「对比」进入分屏对比并选择两个方案；③ 切换方案与各控制方块。
- 源码在 `src/`；`node scripts/build-client-h5-layouts.mjs` 重新生成。效果图复用风格探索稿的后台真实出图。

| 布局 | 方案页 | 调整页 |
| --- | --- | --- |
| ① 沉浸全屏 | 效果图满屏，左右滑动切换；底部可拖起抽屉放详情 | 效果图保持全屏，底部抽屉切换软装风格与石材 |
| ② 画廊对比 | 大卡片纵向排列；分屏对比两个方案，差异逐项高亮 | 当前 / 调整后前后对照，下方选项列表 |
| ③ 仪表板 Bento | 效果图主方块 + 硬装、软装、3D、状态小方块 | 控制面板式方块：软装、石材、规格、波打线 |
