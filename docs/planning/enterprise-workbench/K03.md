## Problem Statement

已有 Agent 只服务单层个人项目，工具只能改家具布局与视觉风格，不能为企业项目出包含铺贴与软装的整体方案。

## Solution

把 Agent 运行时接入企业工作空间的空间项目，扩展受限工具：铺贴（选石材、规格、铺法、波打线）、软装风格、多楼层家具布局；结果为候选，由成员采用为待审方案。

## User Stories

1. As an 企业成员, I want 对 Agent 说“客厅大气一点，二层主卧新中式”, so that 得到整体方案候选。
2. As an 企业成员, I want Agent 只能在企业目录和校验规则内出方案, so that 不会出现企业没有的石材或排不下的布局。

## Implementation Decisions

- 沿用 ADR-0002 / ADR-0005：统一对话入口、Worker 内调用模型、流式回复、关页不取消、持久事件；工具执行层强制目录、版本、排版与碰撞校验，越权或非法组合被拒并返回原因。
- 新增工具：读取饰面与目录、设置铺贴、选择软装风格、按楼层与房间规划家具布局、出图；工具只写候选。
- 采用候选需成员确认，采用后成为线索的待审方案，走 S01 的发布流程。
- 权限：只有该企业成员可在其项目上运行 Agent；客户端与分享预览不可见对话。
- 无模型配置时返回明确的“未配置模型”，不模拟结果。

## Testing Decisions

- [ ] 真实模型 + 合成样本：一轮对话产出硬装 + 软装候选并通过校验；越权与非法组合被拒；重试与恢复不重复写入。
- [ ] HTTP + PostgreSQL：非成员不可运行；候选未采用前客户不可见。

## Out of Scope

客户端 Agent；个人工作台改造。
