# 企业工作台交互原型（P02）

供产品负责人审阅企业成员界面的电脑端可点击原型：纯前端、演示数据、不接服务端。**只用于审阅，不作为生产实现的代码基础。** 对应工单 #45（总规格 #42，ADR-0007、ADR-0008）。视觉依据 B 版（家居杂志 / editorial，`example/prototypes/projects` 设计方向对比页右侧）。

## 打开

- 直接用浏览器打开 `index.html`（离线单文件，内嵌脚本、样式、Three.js 与仓耳渔阳体）。建议窗口宽度 1440，兼顾 1280 与 1024。
- 源码在 `src/`，不要直接改生成的 `index.html`。从仓库根运行 `pnpm build`（或 `node scripts/build-enterprise-workbench.mjs`）重新生成。
- 页头的「演示」或页脚「原型审阅导航」可直接跳到任一页面和状态（跳转会重置演示数据），不属于产品界面。
- 演示登录：`consultant@demo-home.example` / `demo-password`。状态存于 localStorage（键 `hestia.enterprise-workbench.v1`）。

## 页面与状态

| 区域 | 页面 / 状态 |
| --- | --- |
| 入口 | 登录（密码错误）；无权访问（非企业成员） |
| 今日 | 需处理数量（请求联系、待审核 / 辅助转换、待批准绑定、本周新线索）；三列待办；最近动态 |
| 线索 | 按状态（全部 / 待审核 / 已发布 / 客户已确认）与跟进（请求联系、待批准绑定、新线索…已搁置）筛选；搜索；无结果 |
| 线索详情 | 客户（成员可见完整手机号）、需求与偏好、方案效果图与切换、客户动作时间线（确认、留言、请求联系）、饰面清单；跟进状态与内部备注；分享与绑定（主客户与解绑、绑定申请批准 / 拒绝、分享链接与撤销、操作记录） |
| 审核与转换 | DXF 转换结果（三层平面、核对提示）→ 生成待审方案（出图中）→ 待审方案与排版提示 → 发布确认；辅助转换：下载原图、导入户型（校验中 / 失败 / 通过）→ 生成待审方案 |
| 方案与分享 | 预置方案（名称、饰面、石材）→ 生成后弹出分享；分享方式（定向手机号 / 一次性绑定码、有效期）；链接与绑定码只显示一次；撤销、解绑、批准、拒绝的二次确认 |
| Agent 出方案 | 快捷提示、对话与分步进度 → 候选整体方案（硬装 + 软装、校验提示，客户不可见）→ 继续调整或采用为待审方案；超出企业目录被拒；未配置模型 / 无网络时打开预先出好的演示方案 |
| 石材与软装 | 在售与已下架石材版本；三套软装风格（各房间家具组合与配色，示意素材） |

演示数据：企业为「演示家装企业」，品牌位为虚线占位；别墅、饰面与石材沿用 H5 原型（P01），不含任何真实企业、住宅或客户。效果图为浏览器内的简化示意渲染，正式工作台使用后台出图结果。
