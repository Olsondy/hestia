## Problem Statement

空间契约和渲染器只支持单层，没有楼梯与楼板开洞，无法展示完整别墅。

## Solution

空间契约增加楼层、楼板、楼梯与开洞，渲染器支持整栋、单层与剖切查看；导入 house-plan-designer 三层别墅示例作为演示空间。

## User Stories

1. As a 客户, I want 查看整栋别墅以及单独某一层, so that 理解每层效果。
2. As a 客户, I want 看到楼梯连接上下层, so that 别墅空间完整可信。
3. As a 维护者, I want 示例别墅明确标注为演示并保留许可来源, so that 不被误认为真实项目。

## Implementation Decisions

- 契约增加楼层（标高、层高、楼板厚）、楼梯（直跑与 U 形，带踏步数与升高）、楼板开洞（楼梯井、挑空）；所有楼层共用一个坐标系，单位与 x/z 约定不变。单层项目保持兼容，不需要迁移改写。
- 校验：楼梯着地端与到达端落在对应楼层地面，开洞覆盖楼梯上方净空不足处，楼层顺序与标高一致。
- `floorplan-import` 支持 HouseSpec 整栋格式（`floors`）。示例别墅改编自 house-plan-designer 的别墅示例，保留 MIT 声明并更新 `THIRD_PARTY_NOTICES.md`，标注演示。家具作为预设氛围道具保留，不参与本规格的布局能力。
- 渲染器（交互与后台出图共用）支持整栋、单层、剖切到某层；楼梯与开洞正确显示。

## Testing Decisions

- [ ] 契约夹具：楼梯两端、开洞、楼层对齐的成功与失败样例。
- [ ] 示例别墅导入后三层齐全，楼梯连接正确，房间闭合；单层旧项目渲染结果不变。
- [ ] 后台出图得到整栋与单层两类图片并人工核对；交互查看组件随 H5 实现验收。

## Out of Scope

多楼层的家具布局规划、楼梯参数化编辑界面、电梯、地下室下沉区以外的特殊结构。
