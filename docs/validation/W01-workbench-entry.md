# W01 企业工作台入口与成员登录验证

日期：2026-11-03。范围：工单 #46。本机 PostgreSQL（127.0.0.1:54329）、Next.js dev（127.0.0.1:3000）、出图 Worker，演示数据由 `pnpm demo:seed` 准备；短信为模拟发送。浏览器验收使用 Playwright Chromium。

## 实现要点

- **路由**：`/w/{企业标识}`（今日）及 `/login`、`/leads`、`/new`、`/stones`，独立根布局与样式 `app/(enterprise)`，不加载客户端或个人工作台样式。`HESTIA_HOME_ENTRY` 只改根路径，`/w/` 不受影响。
- **依据原型**：页头、登录、无权访问与「今日」按定稿原型 P02 移植，样式表由原型样式整体迁移（去掉审阅按钮），后续页面沿用。线索、预置方案、石材与软装三页先显示“还在准备中”，分别由 W02、W04、W05 接入；页头搜索随 W02 加入。
- **成员校验**：新增 `GET /api/workspaces/by-slug/{slug}`，只按服务端成员关系返回企业工作空间。未登录 401；客户账号、其他企业成员、不存在或格式不对的标识一律 403「这个账号不是本企业的成员」，不区分企业是否存在；查询不创建个人工作空间。
- **登录**：复用邮箱密码登录（`/api/auth/sign-in/email`），工作台不开放注册。未登录访问任一子页面跳转登录并带 `next`，登录后只回跳本工作台内的路径。非成员登录后显示“这个账号不是本企业成员”，可“换一个账号登录”；退出时清掉缓存的会话与线索。
- **今日**：用现有线索接口汇总三栏：请求联系（客户留言中请求联系）、待审核与辅助转换（`pending_review` / `assisted_conversion`）、待批准绑定（待处理的绑定申请），以及最近 7 条动态（提交、发布、确认、留言、绑定申请）。S02 完成前没有跟进状态，请求联系会一直列出，S02 后按跟进状态过滤。页头“今日”计数为需处理的线索数。客户手机号脱敏显示，系统默认的“手机用户 尾号”名字不重复显示。
- **主题**：页头切换浅色 / 深色，选择存 localStorage（`hestia.workbench.theme`），首屏前应用，未选择时跟随系统。
- **演示成员**：`pnpm demo:seed` 为演示成员设置密码并输出工作台地址和登录信息（存于 `private-data/demo/member.json`，`--reset` 不更换）；此前种子里的随机密码会被替换一次。
