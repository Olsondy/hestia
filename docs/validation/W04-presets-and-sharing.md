# W04 预置方案、分享与绑定管理验证

日期：2026-11-03。范围：工单 #49。本机 PostgreSQL、Next.js dev（127.0.0.1:3000）；未运行出图 Worker。

## 实现要点

- **预置方案** `/w/{企业}/new`（按原型）：方案名称、内部说明；按楼层在示例别墅平面上选饰面（复用客户端 `PlanDrawing`）；石材最多 3 款，按选择顺序优先；“按规则生成方案”调用现有成员接口，生成后进入线索详情。草稿存本机，关页后仍在。“交给 Agent 出方案”待 K03 / W07，不放不可用按钮。
- **分享**（ADR-0012）：线索详情底部“分享给客户”与「分享与绑定」中的“新建分享”打开弹层：客户手机号选填（填了只有该号码能直接绑定），有效期 7 / 30 / 90 天；生成后只显示一次分享码与分享口令，分别可复制，明确提示关闭后不能再查看。
- **绑定管理**：待批准申请显示完整手机号与说明，可“核对无误，批准绑定”或拒绝；有效的分享码可撤销；主客户可解绑。均二次确认，危险操作用描边危险色按钮；结果立即反映在分享列表（有效 / 已使用 / 已撤销 / 已过期）与记录。
