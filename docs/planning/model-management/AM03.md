## Problem Statement

多家企业共用模型时，没有办法限定每家能用哪些模型、能花多少，也没有防止一家占满并发的机制。

## Solution

平台管理员为每家企业分配可用模型、月度额度（元）与 Agent 并发上限；企业管理员在分配范围内启用与设默认；每次调用按金额预占额度。

## User Stories

1. As a 平台管理员, I want 给企业分配模型、设月度额度与并发上限, so that 费用与资源可控。
2. As an 企业管理员, I want 在已分配的模型里启用、停用、设默认, so that 成员用合适的模型。
3. As an 企业成员, I want 额度用完时得到明确提示, so that 知道该找谁。

## Implementation Decisions

- 分配表（企业 × 模型，含企业侧启用状态与默认标记）与企业额度设置（月度额度，可设为“不限”：只计量不停止；并发上限）；只有已准入模型可分配。
- 预占：调用前在事务内锁定企业本月额度行，检查“已用 + 已预占 + 本次预占 ≤ 额度”后写入预占；结束按实际用量结算，未知用量按预占计入并标记未核对。超额不发出调用，任务进入可恢复状态（`QUOTA_EXCEEDED`）。月份按 Asia/Shanghai。
- 企业并发上限用 M03 的按企业公平队列；模型总并发上限跨企业共享，超出排队。
- 企业工作台「设置 · 模型」仅企业管理员可见可改；平台后台「企业」页管理分配与额度。
