## Problem Statement

客户需要在不懂设计的情况下调整方案并确认，企业需要知道客户的选择。

## Solution

服务端在已发布方案上提供选项式调整，确定性重新出图；客户确认具体方案版本并可留言或请求联系。

## User Stories

1. As a 客户, I want 换某个空间的石材或铺法并很快看到新效果, so that 找到满意的组合。
2. As a 客户, I want 撤回上一次调整, so that 可以放心尝试。
3. As a 客户, I want 确认方案并留言或请求联系, so that 企业跟进。
4. As an 企业成员, I want 看到客户确认的具体版本和留言, so that 按客户选择报价施工。

## Implementation Decisions

- 选项限定为目录内石材、允许的规格与铺法、波打线开关；每次调整生成新候选修订，经 D04 校验后重新出图，不合格选项不提供或给出原因。
- 确认绑定具体候选版本，沿用现有采用与撤销规则；确认、留言、联系请求写入线索记录。
- 同一调整重复提交不重复出图；出图进行中可继续浏览已有结果。

## Testing Decisions

- [ ] 调整生成新修订并出图，撤回恢复上一版本；非法选项被拒绝。
- [ ] 确认绑定版本，之后的修改不改变已确认内容；线索记录包含确认与留言。
- [ ] 经 HTTP 接口完成调整、撤回与确认；页面在 H5 实现中验收。

## Out of Scope

自由编辑几何、对话调整、报价。
