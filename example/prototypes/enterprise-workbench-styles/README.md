# 企业工作台风格对比稿

企业工作台从家居杂志改为柔和中性（[ADR-0011](../../../docs/decisions/0011-unified-soft-neutral-for-enterprise.md)）前的选型稿：只做内容最多的两页（方案工作台、线索列表），比较三个方向；每个方向都带浅色与深色两套主题。演示数据，只用于选方向，不作为实现依据。所有方向都遵守 [界面工程准则](../../../docs/design/ENGINEERING_RULES.md)：实心表面、不用毛玻璃，状态用中性底加文字，面板里不再套有底色的块。

- 直接用浏览器打开 `index.html`（离线单文件，建议 1440 宽）。顶部深色条切换页面、方向与主题，不属于产品界面。
- **A 停靠**：方案面板与 Agent 助手贴边占满高度，各用一条细线与画面分开；圆角最小，强调色石绿。
- **B 悬浮**：画面铺满整个区域，两侧面板是浮在画面上的实心圆角面板；强调色陶土。窄屏同时开两侧面板时画面偏窄，需要自动收起一侧。
- **C 画框**：面板与页面同底色、无边框；效果图像装裱的画放在更深的画布上，标签在画框上方；强调色板岩蓝。
- 方案工作台可切换方案（含 Agent 候选 D）、楼层、效果图 / 3D，收起左侧面板或 Agent 助手。
- 源码在 `src/`；`node scripts/build-enterprise-workbench-styles.mjs` 重新生成。
