## Problem Statement

三个 pg-boss 队列（设计任务、出图、图纸转换）对所有企业先到先得，一家企业批量出图会让另一家长时间排队；用量也无法按企业汇总，无法与企业结算。

## Solution

后台任务携带所属工作空间，Worker 按工作空间限制同时运行数；AI 与出图用量可按工作空间和时间段查询。

## User Stories

1. As an 企业成员, I want 别家批量出图时我的出图仍能及时开始, so that 不受别家用量影响。
2. As a 维护者, I want 按企业和月份查看 AI 调用与出图用量, so that 能和企业结算。

## Implementation Decisions

- 入队时记录工作空间；领取时某工作空间运行中的任务达到上限则跳过、先领其他工作空间的任务。上限按队列配置，可按工作空间覆盖（工作空间配置）。
- 不改变现有幂等、重试与崩溃恢复语义。
- 用量查询命令 `pnpm usage:report [--workspace <slug>] --month YYYY-MM`：设计任务按工作类型计数并汇总供应商用量（未知用量标为未核对，不记零），出图计次数与耗时，图纸转换计次数。

## Testing Decisions

- [ ] 后台任务 + PostgreSQL：A 一次提交超过上限的出图时，B 的出图在 A 的任务全部完成前被领取；上限内行为与原来一致；崩溃恢复后计数正确。
- [ ] 用量报告对合成数据的按企业、按月汇总正确，未知用量单独列出。

## Out of Scope

计费、账单与额度扣减规则；用量界面；按企业独立 Worker。
