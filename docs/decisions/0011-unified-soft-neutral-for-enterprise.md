# 企业工作台与 H5 客户端统一为柔和中性风格

2026-10-25 的决定把家居杂志（editorial）定为唯一生产视觉基线，企业工作台规格 #42 也以它为依据。H5 客户端随后在风格探索中改选了 A 柔和中性（P03 定稿）。企业工作台原型加入 Agent 助手面板、效果图与 3D 同屏之后，家居杂志靠细分隔线分组、大号展示标题的做法在信息密集的方案工作台里变成满屏线框，用户于 2026-11-03 审阅时判断这种风格不适合内容多的工具界面，决定整体更换。

## 决定

- **范围**：企业工作台全部页面改为柔和中性，与 H5 客户端共用同一套配色、字体（仓耳渔阳体 400 / 500）与组件语言；版式按电脑端与手机端分别设计。
- **原则**：用底色、圆角面板与留白分组，不用分隔线堆叠层级；方案工作台以效果图 / 3D 画面为中心，方案信息与 Agent 助手作为可收起的辅助面板。
- **主题**：浅色与深色两套主题是同一方案的组成部分，两端都必须提供，默认跟随系统。
- **规则**：遵守 `docs/design/ENGINEERING_RULES.md`；两端各自的规则见 `docs/design/H5_UI_DESIGN.md`、`docs/design/WEB_UI_DESIGN.md`。
- **流程**：先做方案工作台与线索列表两页的风格对比稿（几个方向，每个方向都带浅色与深色主题），用户选定后重做 P02 原型，并据此替换 `DESIGN.md` 中的生产视觉基线。
- **个人工作台**（`example/prototypes/projects`）目前暂停，是否跟随更换在恢复时另行决定；家居杂志方向保留为该原型的现状。

## 影响

- 覆盖 2026-10-25「生产 UI 只采用家居杂志」中关于企业工作台与客户端的部分，以及规格 #42「视觉依据 B 版（家居杂志）」的描述。
- P02 原型需要重做后再审阅，W01 之后的工作台界面工单继续等待 P02 通过。
