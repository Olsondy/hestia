# AM04 调用级用量记录与统计页面验证

日期：2026-11-14。范围：工单 #70，依据 ADR-0018。PostgreSQL 17.7（局域网主机上的本地 Compose 容器，经 SSH 隧道映射到 127.0.0.1:54329），HTTP 路由处理函数直接调用；不调用任何模型。

## 实现要点

- **调用记录**沿用 AM03 的 `model_calls`：企业、成员、任务、模型、单价版本、输入与输出 token、未核对标记、金额（分）、耗时、结果，预占与结算各在自己的事务里写入。月份在预占时按 Asia/Shanghai 取自然月。
- **汇总**（`packages/model-registry/src/usage.ts`）：只汇总已结算的调用，进行中的调用在额度摘要里显示为“预占中”。每次调用按它预占时的单价版本计价，改价不重算历史；未核对的调用按预占额计入并单独计数。
- **平台**：`/api/admin/usage?month=&by=workspace|model` 与 `/api/admin/usage/export`（CSV，UTF-8 BOM，金额以元两位小数，与页面同一份数据；以 `=`、`+`、`-`、`@` 开头的单元格加前缀，防止表格软件当作公式执行）。后台「用量」页：月份与汇总方式切换、合计行、导出。
- **企业**：`/api/workspaces/{id}/usage?month=&by=member|model`，只有企业管理员可看，成员 403，另一家企业的域名上 404；不显示单价。工作台「企业设置 · 用量」页。
- **`pnpm usage:report`**：每家企业增加 `billing`（调用次数、token、未核对次数、金额，分模型明细）。
