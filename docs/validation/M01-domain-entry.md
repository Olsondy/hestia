# M01 按域名接入企业工作空间验证

日期：2026-11-10。范围：工单 #59，依据 ADR-0017。PostgreSQL 17.7（局域网主机上的本地 Compose 容器，经 SSH 隧道映射到 127.0.0.1:54329），HTTP 路由处理函数直接调用。

## 实现要点

- **数据**：迁移 `0005_workspace_domains`：`workspace_domains(host 主键, workspace_id)`，主机名小写、不含端口，数据库约束校验格式；删除工作空间时随之删除。
- **命令**：`pnpm workspace:domain <slug> add|remove <host>`，不带动作时列出。重复登记同一企业不变；已登记给其他企业的域名 409；带协议、端口、路径或 IP 的值 400。
- **识别**：按 `Host` 头确定企业；经代理时由 `HESTIA_HOST_HEADER` 指定转发头，取列表最后一项（与限流读取客户端地址的规则一致）。页面 `/`、`/c`、`/w` 先看已登记域名，再回退到 `HESTIA_HOME_ENTRY`。
- **接口范围**：在已登记域名上，16 个 `/api/client/{企业}/…` 接口、手机号验证码发送与登录、`/api/share/{分享码}` 预览、场景与图片，以及 `/api/workspaces/{id}/…`、`/api/workspaces/by-slug/{slug}` 只接受该域名的企业；其他企业与不存在的企业返回相同的 404，不透露另一家企业是否存在。
- **来源校验**：写操作的来源校验（`sameOrigin`、better-auth `trustedOrigins`、采用方案的浏览器校验）原来只认 `BETTER_AUTH_URL`；现在也接受「请求所到的已登记域名」，协议须与 `BETTER_AUTH_URL` 一致。别家的已登记域名或未登记域名作为来源一律拒绝。
- **未登记域名**：接口不按企业限制，与单企业部署相同；页面回退到 `HESTIA_HOME_ENTRY`，未设置时不接到任何企业。不同企业的账号隔离由 M02 负责。
- 开发服务器允许 `*.localhost`，供 M06 的本地两企业验收使用。

断言：主机名规范化（大小写、端口、末尾点；IP 与无点主机名不识别）；转发头取最后一项；登记幂等、跨企业占用 409、非法值 400、不存在的工作空间 404；增删与列出。A 域名下 A 的目录 200，B 与不存在的企业得到相同的 404 响应体，未登记域名下 B 200。A 域名下用 B 的入口发验证码 404；以 B 域名或未登记域名为来源 403，协议不一致 403。A 域名下读 B 的工作空间（按 id 或 slug）404，未登记域名下 200。分享码在本企业域名下 200，在另一企业域名下 404 `SHARE_UNAVAILABLE`，未登记域名下 200。
