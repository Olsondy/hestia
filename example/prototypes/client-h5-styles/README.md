# H5 客户端风格探索稿

为小程序 / H5 客户端重新选定视觉风格（替代 P01 的家居杂志营销风）而做的对比稿：同一内容、同样四个页面（首页、方案、调整、确认），三种方向并排。参考 Orbix Studio 的 Orelax（地产）与 Gen.ho（智能家居）案例、Awwwards 移动端入围作品的产品化 App 语言。

- 直接用浏览器打开 `index.html`（离线单文件），点顶部切换页面，页内按钮可切换方案、软装风格与硬装石材。
- 源码在 `src/`；`node scripts/build-client-h5-styles.mjs` 重新生成。
- 效果图 `assets/` 由后台出图管线（ultra、室内人视角预设镜头）渲染示例别墅的三个规则方案，石材为程序生成的示意素材；软装风格为示意标签，家具随风格变化在 K01 实现。

| 方向 | 要点 |
| --- | --- |
| A · 柔和中性 | 暖浅灰底、白色大圆角卡片、近黑强调与主按钮；底部悬浮药丸导航 |
| B · 夜色沉浸 | 近黑底、效果图满版到顶、毛玻璃浮层、荧光绿点缀 |
| C · 森绿暖阳 | 浅底配深森绿色块、暖黄主按钮、Bento 卡片 |

选定方向后，按该风格重做完整 H5 原型（P03），再进入实现。
