## Problem Statement

成员需要在工作台里与 Agent 对话出整体方案，并核对、采用结果。

## Solution

在线索详情与预置方案中加入 Agent 面板：对话、进度、候选方案（效果图、硬装与软装清单、校验提示）、采用为待审方案。

## User Stories

1. As an 企业成员, I want 在线索里直接让 Agent 出方案, so that 不用切到别的页面。
2. As an 企业成员, I want 对比 Agent 的候选与现有方案再决定采用, so that 方案质量可控。

## Implementation Decisions

- 按获批原型实现；对话为流式，关页后回来能看到进行中的任务与结果。
- 候选显示效果图、硬装与软装清单、校验提示；采用需确认，采用后进入审核发布（W03）。
- 未配置模型或网络不可用时如实提示，可打开预先出好的演示方案。

## Testing Decisions

- [ ] 真实浏览器：对话 → 候选 → 采用 → 发布 → 客户端可见；刷新恢复进行中的任务。

## Out of Scope

多人同时编辑同一候选。
