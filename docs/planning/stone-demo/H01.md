## Problem Statement

服务端能力和获批原型都就绪后，需要把 H5 客户端实现为可用的产品界面，接通两条入口。

## Solution

按获批原型实现 H5 客户端，接入 D02、D05–D08 的服务端接口与 D03/D04 的渲染能力，完成客户自助与分享绑定两条流程。

## User Stories

1. As a 客户, I want 用手机号登录并在演示模式看到验证码提示, so that 能进入企业入口。
2. As a 客户, I want 选择示例别墅或上传图纸、选空间和石材后提交, so that 得到方案。
3. As a 客户, I want 看到出图进度、待审核或需辅助转换的状态, so that 知道接下来会发生什么。
4. As a 客户, I want 查看效果图与 3D 并比较 2–3 个方案, so that 做出选择。
5. As a 客户, I want 换石材或铺法、撤回、确认并留言, so that 表达我的选择。
6. As a 客户, I want 打开分享链接直接预览，登录后完成绑定, so that 继续调整与确认。
7. As a 客户, I want 关页或刷新后回到原来的进度, so that 不会丢失操作。

## Implementation Decisions

- 以获批原型为交互与视觉依据；与原型的偏差需要说明原因并让用户确认。
- 页面属于 Web 应用的客户端路由，按工作空间入口区分企业；只调用公开 HTTP 接口，不绕过服务端授权。
- 3D 查看复用 `scene-runtime`，效果图使用后台出图结果；字体与贴图本地加载以支持离线演示。
- 使用 Impeccable，延续家居杂志方向与仓耳渔阳体，不启用 hooks。

## Testing Decisions

- [ ] 真实浏览器手机视口完成两条入口的完整流程，覆盖刷新恢复与列出的状态。
- [ ] 视觉与获批原型一致，逐页截图并完成独立视觉复核。
- [ ] 未登录、非绑定客户与其他企业入口无法访问不属于自己的项目。

## Out of Scope

成员工作台、小程序、真实短信、对话式调整。
