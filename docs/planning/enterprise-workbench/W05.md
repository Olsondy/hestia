## Problem Statement

成员看不到企业石材库与软装风格，不清楚客户可选的材料与搭配。

## Solution

新增成员只读目录接口与页面：石材（示意贴图、名称、表面、可选规格、版本、是否下架）与软装风格（各房间类型的家具组合与材质、版本）。

## User Stories

1. As an 企业成员, I want 浏览企业石材库, so that 了解客户可选的材料。

## Implementation Decisions

- 接口只读，仅本企业成员可访问；返回当前与已下架版本（标记）。
- 页面按获批原型实现，贴图为程序生成的示意素材并标注。

## Testing Decisions

- [ ] HTTP + PostgreSQL：成员可读，客户与其他企业不可读。
- [ ] 真实浏览器：石材库页面。

## Out of Scope

上传、编辑、下架石材。
