## Problem Statement

需要在企业现场断网演示两条客户端入口，并保证演示数据可重复准备、不含真实企业资料。

## Solution

种子脚本经正式服务接口准备演示企业、成员、客户、示例别墅项目和定向分享链接；整理演示脚本并在断网条件下完成验收。

## User Stories

1. As a 演示者, I want 一条命令准备好全部演示数据, so that 现场前快速复位。
2. As a 演示者, I want 断网也能走完两条入口, so that 不依赖现场网络。
3. As a 演示者, I want 一份演示步骤说明, so that 按顺序讲解企业端与客户端。

## Implementation Decisions

- 种子脚本调用正式服务接口，不直接写表；重复执行结果幂等，可以重置。演示数据全部标注演示，不含真实企业名称和素材。
- 预置：演示企业工作空间与成员、两位演示客户手机号、已发布的示例别墅方案及其定向分享链接与绑定码。
- 离线：字体、贴图、示例数据与前端资源本地加载；短信为模拟发送；不调用模型。
- 演示步骤写入 `docs/` 下的演示说明，README 至多加一行链接。

## Testing Decisions

- [ ] 在断开外网的本机环境完成：客户自助入口全流程；打开预置分享链接预览 → 登录 → 绑定 → 调整 → 确认。
- [ ] 种子脚本重复执行不产生重复数据；重置后可再次演示。
- [ ] 手机真机或手机视口的视觉核对记录。

## Out of Scope

生产部署、真实短信、企业真实数据导入。
