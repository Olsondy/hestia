## Problem Statement

> 2026-11-03 按 [ADR-0013](../../decisions/0013-drawing-requests-without-review-gate.md) 缩小范围：DXF 不再待审核。

排队中的照片、PDF、DWG，以及客户主动交给企业的图纸，需要成员在界面上整理户型后出方案；开启“全部审核后发布”的企业需要发布入口。

## Solution

实现辅助转换（整理队列）：查看客户的图纸，导入整理好的户型，导入后自动出方案并发布；仅对开启“全部审核”的企业显示审核发布。

## User Stories

1. As an 企业成员, I want 看到待审方案的效果图与提示后发布, so that 客户只看到可靠方案。
2. As an 企业成员, I want 为非 DXF 图纸导入整理好的户型, so that 这类需求也能出方案。

## Implementation Decisions

- 按获批原型实现，调用 S01 与 D05 的辅助导入接口；发布需要二次确认。
- 出图进行中显示进度，完成后可发布；全部方案不通过校验时显示原因。

## Testing Decisions

- [ ] 真实浏览器：DXF 待审核 → 生成待审方案 → 核对 → 发布 → 客户端可见；辅助导入户型 → 生成 → 发布。

## Out of Scope

在界面中绘制或编辑户型。
