# 开发与验证

## 可复现入口

根目录安装 Node.js 22+ 依赖：`npm ci`。`package-lock.json` 锁定版本，避免不同机器自行漂移依赖。

| 命令 | 作用 |
| --- | --- |
| `npm run build` | 从 `src/` 构建单文件离线 HTML `dist/index.html` |
| `npm test` | 检查编辑原子性、固定物品保护、存储及撤销重做、演示指令 |
| `npm run check` | 依次运行以上两步 |
| `npm run preview` | 仅在 `127.0.0.1:4173` 提供本地预览 |
| `npm run fonts` | 按当前文案更新标题字体子集与许可（需要网络，普通构建无需） |

构建不启动服务器、不上传文件。构建脚本通过自身位置定位仓库，不依赖开发者绝对路径。

## 自动检查的覆盖与边界

`scripts/check.mjs` 是数据层测试：编辑失败时回滚、固定物品不可移动、保存恢复与撤销重做、演示指令的单位换算与越界拒绝。它不运行 WebGL，不验证屏幕效果，也不做工程碰撞或通行分析。

GitHub Actions 在 Windows / Linux 运行构建与测试，并确认提交的 `dist/index.html` 与源码一致；不包含浏览器截图测试。CI 是否通过以实际运行结果为准。

## 浏览器人工验收

视觉或交互改变时，至少在桌面 1440、窄桌面 1100、小屏 390 下检查：空项目、搜索空结果、错误导入、校准、拖动、锁定、撤销、演示对话、材质与昼夜、展示页、刷新恢复。历次记录见 [原型验证记录](prototype-review.md)。

## 运行时数据

原型采用 ES modules + Three.js + esbuild；生产版本拟用的 Next.js 等技术属于后续计划。`dist/index.html` 内嵌运行时代码、CSS、图标、Noto 标题字体和对应许可，运行时无需字体 CDN，也不请求模型。

项目使用 localStorage 键 `hestia.studio.v1`。不同浏览器和 origin 的数据独立；localhost、127.0.0.1、file 路径之间不共享。图片限 8 MiB，最长边缩至 1600px 后存储；空间不足会明确提示保存失败。JSON 导出目前用于保留数据，不提供重新导入入口。

自定义户型仅支持直墙段和少量参数家具；房间自动分区、门窗编辑、自定义户型漫游、真实模型对话和工程碰撞检查尚未实现。内置示例项目的三套布局来自 `src/sample/`，自定义图片不会被替换成示例。新增字段需要考虑已存在的浏览器数据和撤销快照。
