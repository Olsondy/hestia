## Problem Statement

H5 客户端只能调整硬装，客户无法选择软装风格。

## Solution

按获批原型在 H5 客户端加入软装风格切换，接入 K02 接口；结果、调整与确认页显示硬装与软装。

## User Stories

1. As a 客户, I want 在手机上切换软装风格并看到新的效果图, so that 选出喜欢的整体效果。

## Implementation Decisions

- 复用 H01 的修订、出图等待与确认流程；切换风格同样生成新修订，确认后再调整需重新确认。
- 调整页改为多处修改累积后统一出图，需新增批量提交修改的接口（2026-11-03，见 `docs/decisions/0010-client-adjust-batch-rerender.md`）；组件与 token 按 `docs/design/H5_UI_DESIGN.md` 迁移。
- 2026-11-03 用户决定先把可看的页面做好：H5 界面已按 v2 原型提前改版（组件、token、浅色 / 深色、沉浸方案页、统一出图的调整页）。本工单剩余部分是接入服务端，已完成：
  - 软装风格：方案的当前风格与可选风格来自 K02（`softStyle`、`softChoices`），首页列出企业目录的风格；`soft-styles.ts` 的本机演示数据已删除。
  - 批量调整：新增 `POST …/schemes/{id}/adjust-batch`（一次提交多处修改与可选的软装风格，生成一个修订、只出一次图，冲突时整批不生效）；`adjustBatch` 改为调用它。

## Testing Decisions

- [x] 真实浏览器手机视口：切换风格 → 出图 → 确认；分享绑定后同样可切换。见 [H02 验证](../../validation/H02-client-soft-styles.md)。
