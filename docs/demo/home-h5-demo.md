# 家装 H5 离线演示说明

面向企业现场的客户端演示（ADR-0007、规格 #29；演示企业为一站式家装企业）。演示两条入口：**客户自助**（提交需求得到铺贴方案）和**成员分享**（在首页输入企业预置方案的分享码，登录绑定后调整、确认）。全部数据为演示数据，石材为程序生成的示意素材，不含任何真实企业资料；不调用模型，短信为模拟发送，断网可用。

## 一次性准备（演示电脑）

需要 Node.js 22+、pnpm、本机 PostgreSQL（`pnpm db:up` 用 Docker 启动，或自备实例）。

```sh
pnpm install --frozen-lockfile
pnpm db:up        # 本地 PostgreSQL（Docker）；已有数据库可跳过
pnpm bootstrap    # .env、迁移、队列、出图浏览器、DXF 环境；每步可重复执行
```

在 `.env` 中加入演示部署配置：

```sh
SMS_PROVIDER=mock                 # 模拟短信：验证码显示在登录页；生产环境会拒绝启动
HESTIA_REGISTRATION=closed        # 关闭工作台开放注册
HESTIA_HOME_ENTRY=demo-home      # 根路径官网入口页的两扇门接到演示企业（客户端 / 工作台），见 ADR-0015
HESTIA_OTP_MAX_PER_SOURCE=200     # 同一台电脑上的所有“客户”共用一个来源额度
HESTIA_OTP_MAX_PER_PHONE=30
NEXT_TELEMETRY_DISABLED=1
```

以上演示配置不要用于跑 `pnpm test:db`（验证码限流测试按默认额度断言）。

手机连同一局域网演示时，把 `BETTER_AUTH_URL` 改成电脑的局域网地址（如 `http://192.168.1.20:3000`），并设置 `HESTIA_WEB_HOST=0.0.0.0` 让 Web 服务监听局域网；只在电脑浏览器（手机模式）演示时保持 `http://127.0.0.1:3000`。

## 每次演示前

```sh
pnpm demo:seed --reset    # 复位演示数据，并预生成预置方案的效果图
```

命令会输出入口地址、两个分享码（一个指定手机号，一个不指定）、演示手机号，以及企业工作台 `/w` 的演示成员邮箱和密码（另存于 `private-data/demo/`，不提交仓库）。预生成 6 张效果图：无显卡的电脑每张约 1.5–2 分钟，请提前完成。不带 `--reset` 重复运行不会产生重复数据，只在分享码失效（已绑定、过期或撤销）时重新分享。演示数据只用于演示与开发环境：`SMS_PROVIDER` 不是 `mock` 或 `NODE_ENV=production` 时，命令直接停止、不改动任何数据；`--reset` 也只删除演示企业 `demo-home` 与演示手机号的数据。正式环境的企业用 `pnpm workspace:create` 开通，石材与软装目录导入企业自己的资料。

然后在一个终端启动全部服务（Web、出图 Worker、图纸转换 Worker，Ctrl+C 一起停止）：

```sh
pnpm dev:all
```

需要单独运行时仍可分别使用 `pnpm dev`、`pnpm worker:render`、`pnpm worker:import`。

**给别人远程演示（公网或隧道访问）时改用生产构建**：开发模式的页面约大 4 倍，且每个页面首次访问要现场编译。`.env` 里加 `HESTIA_DEMO=1`（只有设置它，模拟短信才允许在生产构建下运行），然后：

```sh
pnpm demo:build   # 每次拉取新代码后重新构建，约 1–2 分钟
pnpm demo:start   # 生产模式的 Web + 两个 Worker，用法同 dev:all
```

生产模式下改代码不会自动生效，开发调试仍用 `pnpm dev:all`。效果图在浏览器支持时以 WebP 返回（约 50 KB，原图 PNG 约 1 MB），下载原图仍是 PNG。走 cloudflared 等隧道时另加 `HESTIA_OTP_SOURCE_HEADER=cf-connecting-ip`。

## 讲解顺序

1. **企业入口首页**（根路径 `/` 点「进入客户端」，或直接 `/c`）：效果图封面、流程三步、企业石材库（示意素材）。
2. **客户自助**：提交方案需求 → 手机号登录 → 选示例别墅 → 在平面图上勾选饰面 → 挑选最多 3 款石材与偏好 → 提交。页面显示“正在排版出图”，可以先切到第 3 步讲分享，回来再看结果。
3. **成员分享（定向手机号）**：在首页点「收到企业的分享码？」输入定向分享码（也可以粘贴整段分享口令），未登录即可预览 3 个方案的效果图和差异表；点“调整”说明需要登录与绑定；用 138 0013 8000 登录，自动绑定。
4. **方案与 3D**：切换方案、查看差异表与饰面清单；切到“3D 查看”拖动旋转，选预设视角。效果图为后台高画质出图，3D 为实时预览。
5. **调整与确认**：换石材、规格、铺法或波打线，排版校验不通过会提示冲突且方案不变；通过则生成新修订并重新出图（约 1–2 分钟），可撤回。确认方案并留言、请求联系；确认后再调整需要重新确认。
5b. **软装风格**：方案页显示每个方案的软装风格（现代简约 / 轻奢 / 新中式）；调整页可在三套之间切换，并与石材修改一起点「重新出图」，生成一个新修订、出一张图（约 1.5–2 分钟）。确认后再切换需重新确认。
6. **绑定规则**：用 137 0013 7000 登录后打开定向分享码，提示手机号不一致、只能预览，可提交绑定申请；输入不指定手机号的分享码，登录即绑定。绑定后分享码失效，别人再输会提示“已使用”。
7. **我的项目**：自己提交的与企业分享的分开显示。

## 演示结束后

```sh
pnpm demo:seed --reset
```

## 验收

服务已启动且运行过 `pnpm demo:seed` 时，`pnpm validate:client-h5` 在手机视口自动走完两条入口，并拦截一切外网请求（有外网请求即失败）。它会使用演示数据，结束后需再次 `pnpm demo:seed --reset`。记录见 [D09 验证](../validation/D09-offline-demo.md)。

## 常见问题

- **“获取验证码过于频繁”**：确认 `.env` 已调高 `HESTIA_OTP_MAX_PER_SOURCE`；或运行 `pnpm demo:seed --reset` 清除演示号码的发送记录。
- **效果图一直“正在出图”**：确认 `pnpm worker:render` 在运行；无显卡时每张 1.5–2 分钟，多个需求排队依次出图。
- **分享码失效**：运行 `pnpm demo:seed`（分享码失效时会重新分享并输出新的分享码）。
- **“已绑定其他客户”**：上一次演示已经绑定，运行 `pnpm demo:seed --reset`。
