## Problem Statement

图纸需求在成员点“发布”时才生成方案并立即对客户可见，成员无法先看效果图和排版提示再决定是否发布。

## Solution

把图纸需求的审核拆成“生成待审方案”和“发布”两步：生成后方案只对成员可见并后台出图，成员核对后发布。

## User Stories

1. As an 企业成员, I want 先生成方案并看到效果图和排版提示, so that 确认可靠后再发布。
2. As an 企业成员, I want 辅助导入户型后用同一流程出方案, so that 非 DXF 图纸也能发布。
3. As a 客户, I want 在企业发布前只看到“等待企业审核”, so that 不被未核对的方案误导。

## Implementation Decisions

- 新增成员接口“生成待审方案”：要求图纸已转换或已辅助导入且候选通过校验；采用候选为项目空间、派生饰面、规则生成 2–3 个方案并后台出图；需求保持待审核，记录生成者。幂等（操作标识），已有待审方案时不重复生成，可显式“重新生成”。
- “发布”对已有待审方案的图纸需求只做发布；没有待审方案时保持现有一步发布行为，兼容 D06。
- 校验不通过的方案不发布；全部不通过时返回可读原因，需求留在待审核。
- 客户端视图在发布前不返回方案（沿用 D06）。

## Testing Decisions

- [ ] HTTP + PostgreSQL：生成后成员可见、客户不可见；发布后客户可见；重复生成幂等；未转换的图纸拒绝生成；非成员 404。
- [ ] 后台任务：待审方案出图，重复投递不重复生成。

## Out of Scope

成员手动修改方案；界面（W03）。
