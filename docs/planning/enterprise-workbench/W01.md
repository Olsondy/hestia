## Problem Statement

企业成员没有进入企业工作台的入口；现有工作台面向个人项目。

## Solution

实现企业工作台外壳：成员邮箱登录、选择所属企业工作空间、导航与首页（今日需处理）。

## User Stories

1. As an 企业成员, I want 打开 `/w/{企业标识}` 用邮箱登录, so that 进入本企业的工作台。
2. As an 企业成员, I want 登录后看到今日需处理的事项, so that 先处理紧急的线索。
3. As a 维护者, I want 客户账号或其他企业成员进入时看不到数据, so that 线索不外泄。

## Implementation Decisions

- 路由 `/w/{企业标识}` 及子页面，独立于客户端根布局；按获批原型实现。
- 复用邮箱登录；登录后校验成员关系，非成员显示“无权访问”，不暴露企业是否存在以外的信息。
- 首页汇总待审核、请求联系、待批准绑定的数量与最近条目，使用 S02 的线索视图。
- `HESTIA_HOME_ENTRY` 只影响根路径；`/w/` 在企业部署中同样可用。

## Testing Decisions

- [ ] 真实浏览器：成员登录进入；客户账号与其他企业成员被拒；未登录跳转登录。

## Out of Scope

成员邀请与角色管理界面。
