# 3D 只看一层的软装与硬装，不做整栋与多楼层浏览

用户于 2026-11-04 指出：3D 的目的是让客户看清一层的软装和硬装效果，“整栋鸟瞰”和逐层鸟瞰客户不关心，还浪费性能。DXF 导入本来就只有一层；多层只来自示例别墅。

## 决定

- **只显示一层**：交互式 3D（H5 客户端、企业工作台方案 3D）只加载一层，默认选硬装地面铺得最多的那一层（示例别墅为一层），不提供楼层切换。
- **保留入户查看**：人眼视高的入户镜头照旧保留，并且只加载所在楼层，不再连带渲染其他楼层。
- **去掉整栋鸟瞰**：预设镜头改为本层的“全层浏览”加入户房间；不再展示整栋和逐层鸟瞰。
- **全层浏览 → 房间 → 入户**（同日用户确认）：默认进入全层浏览，墙体剖到约 1.1 m（远侧外墙和朝向镜头的石材墙面保留全高），明亮柔和的“模型感”光照，房间标签跟随镜头；点标签或房间地面，镜头飞近该房间并显示地面石材、规格与铺法，点「入户查看」进入人眼视高的写实画面。每个有名称的室内房间都可入户。
- **色调保持写实**：全层浏览只调亮度与阴影，色调映射仍为 Neutral，石材颜色在两种看法下一致。
- **数据层不变**：户型与场景契约仍支持多层（运行时的 `building` / `section` 视图留给验证脚本使用），只是不在界面上展示。
- **方向**：后续投入放在单层的观看手感与软装、硬装质感上（参照 hestia-creation 原型的剖切、聚焦和漫游）。

## 影响

- 后台效果图的入户镜头同样只加载本层，渲染更轻。
- 以后真有“一个项目多张楼层图纸”的需求时，另行决定是否加楼层切换。
