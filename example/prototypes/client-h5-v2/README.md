# H5 客户端交互原型 v2（P03）

在风格与布局探索之后重做的完整 H5 / 小程序客户端原型：配色 **A 柔和中性**，布局 **① 沉浸全屏**，浅色 / 深色同一配色、默认跟随手机系统（「我的」中可切换）。纯前端、演示数据、不接服务端，**只用于审阅**。对应工单 #55（总规格 #42，ADR-0008）。获批的 P01（`../client-h5`）保留为历史。

## 打开

- 直接用浏览器打开 `index.html`（离线单文件），建议手机或设备模拟（390×844）。右上角 ≡ 为**原型审阅导航**，可直达 33 个页面与状态（跳转会重置演示数据），不属于产品界面。
- 源码在 `src/`；`node scripts/build-client-h5-v2.mjs` 重新生成。效果图为后台出图管线渲染的示例别墅三个方案（示意素材）。

## 结构

- **底部菜单**：首页 / 项目 / 我的；右侧溢出的圆形「＋ 提需求」按钮即“提交方案需求”入口（首页不再放大按钮）。
- **提交方案需求**为分步页面（户型 → 饰面 → 石材与偏好），不是输入框：客户端不使用生成式 AI，只在给定选项中选择。
- **方案页**：效果图在上方满版、左右滑动或点箭头切换方案、右侧效果图 / 3D 切换；底部抽屉默认显示方案名、软装风格与客厅地面，展开后为软装、硬装清单与三方案差异。
- **调整页**：效果图保持在上方，底部抽屉切换「软装风格 / 硬装石材」，改完重新出图生成新修订，可撤回；冲突时不能出图。
- **确认、分享与绑定、项目、我的**：沿用 P01 的规则（定向手机号自动绑定、手机号不一致、绑定码与锁定、绑定申请、链接撤销 / 过期）。

软装风格为示意标签，家具款式随风格变化在 K01（#52）实现；3D 查看以整栋图示意，正式版为实时 3D。
