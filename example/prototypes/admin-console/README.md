# 平台管理后台交互原型（AM-P）

供产品负责人审阅平台管理后台的电脑端可点击原型：纯前端、演示数据、不接服务端，只用于审阅。依据 [ADR-0018](../../../docs/decisions/0018-admin-managed-models-per-enterprise-quota.md)，工单见 [AM-P](../../../docs/planning/model-management/AM-P.md)。

视觉沿用企业工作台定稿的柔和中性 **B 悬浮**（[WEB_UI_DESIGN.md](../../../docs/design/WEB_UI_DESIGN.md)），样式在 `enterprise-workbench/src/style.css` 之上叠加 `src/style.css`，浅色与深色两套主题（默认跟随系统，页头可切换）。

## 打开

- 直接用浏览器打开 `index.html`（离线单文件）。建议窗口宽度 1440，兼顾 1280 与 1024。
- 源码在 `src/`，不要直接改生成的 `index.html`；从仓库根运行 `node scripts/build-admin-console.mjs` 重新生成（`pnpm build` 也会生成）。
- 页头的虚线「审阅」可直接跳到任一页面和状态（跳转会重置演示数据），不属于产品界面。
- 演示登录：`ops@hestia.example` / `demo-password`。状态存于 localStorage（键 `hestia.admin-console.v1`）。

## 页面

- **模型服务**：列表（每个服务测试连通、全部测试、连通失败提示，下面列出已启用的模型 ID）；登记与管理服务（协议三选一、服务级兼容设置、密钥只显示末四位、超时与总并发；获取模型列表、启用多个模型 ID、不提供列表时手动添加）。
- **模型**（服务里启用的一个模型 ID）：显示名称与说明、模型级参数、单价与单价记录；接入检查（逐项结果、未通过原因）；停用与重新启用。
- **企业**：列表（可用模型、本月用量 / 额度、并发上限）；分配可用模型、月度额度（可设“不限”）与同时运行的 Agent 任务数；超级管理员可「进入工作台（只读）」，进入记入审计。演示账号是超级管理员，审阅导航「普通平台管理员」看没有这个入口的样子。
- **用量**：按月、按企业或按模型汇总调用次数、token、未核对次数与金额，导出 CSV。
- **审计记录**：平台管理员的每次改动。

企业侧的「企业设置 · 模型 / 用量」与 Agent 助手里的选模型在企业工作台原型（`../enterprise-workbench/`）里，审阅导航的「选择模型」「企业设置」两组。

供应商、地址、模型名称都是演示数据，不代表已接入或推荐任何供应商。
