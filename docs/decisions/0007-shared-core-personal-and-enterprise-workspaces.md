# 共享内核服务个人与企业两种工作空间，企业石材硬装以 H5 演示先行

Hestia 从“只面向个人用户”调整为一套共享内核，服务个人和企业两种工作空间。起因是一家以别墅、酒店、展厅为主要客户的石材硬装企业提出需求：企业的客户在手机端注册并提交需求，由产品给出方案，企业据此获得有具体方案的销售线索；企业成员也可以自行为客户制作方案并分享。企业场景先做 H5 可行性演示，用于企业决定是否立项；小程序端在确认可做后以 web-view 内嵌同一 H5，不另建原生实现。

不新建仓库。已验收的候选与采用、固定事实、版本与幂等、后台任务、服务端出图和图纸导入都与使用者身份无关，企业场景直接复用；重写或复制一份会丢掉已验收证据，或让两份代码各自演化。

## 身份与入口

| 身份 | 归属 | 使用的界面 |
| --- | --- | --- |
| 企业成员 | 企业工作空间的成员 | 工作台：Agent、编辑、渲染与校验 |
| 个人用户 | 自己的个人工作空间 | 与企业成员相同的工作台 |
| 客户 | 企业的客户，通过该企业的 H5 / 小程序入口关联到企业工作空间 | 客户端：提交需求、查看方案、在给定选项内调整、确认 |

- 账号全平台唯一，同一个人可以既是某企业的客户，又拥有个人工作空间。与企业的关系单独记录，从哪个企业的入口进入就关联到哪个企业。
- 工作台是通用模块。企业成员与个人用户使用同一套 Agent 与领域工具，差别只来自工作空间配置。企业内部使用 Agent 不属于面向公众的服务；个人场景开放前另行处理备案或登记。
- 客户端首版只提供选项式调整，结果均为确定性渲染，不调用生成式 AI。
- 企业项目有两个入口，落到同一个项目和同一个客户端：客户在客户端提交方案需求，由后台识图与规则生成方案，校验不通过或企业配置要求时由企业成员审核后发布；企业成员在工作台发起项目并分享给客户。
- 分享链接只授予预览，不登录即可查看已发布的方案；转发链接不能获得其他权限。调整、确认或留言需要用已验证的手机号登录，并把项目绑定到客户账号。仅凭链接不能完成绑定，须满足以下条件之一：
  - **定向分享**（默认）：企业成员分享时填写客户手机号，客户登录验证的手机号与之一致时绑定；
  - **绑定码**：未填写手机号时生成一次性、有时效的绑定码，由企业成员通过其他渠道单独告知客户；
  - **成员审批**：以上都不满足时，客户提交绑定申请，由企业成员批准。
- 一个项目只绑定一个主客户，其他人由企业成员或主客户邀请加入。企业成员可以撤销链接、解绑和重新分享，绑定与解绑都留记录。客户自己提交的项目属于本人，无须绑定。
- 手机号验证通过短信发送适配器接入。演示与离线环境可以使用模拟发送，验证码的生成、存储、时效、错误次数与频率限制及绑定规则仍按正式逻辑执行；生产环境不得启用模拟发送。

## 两种工作空间的边界

- 所有项目属于一个**工作空间**。个人工作空间只有一个成员；企业工作空间有多名成员和角色。代码不把“企业”或“个人”写死为唯一形态。
- 用量走同一账本，扣减规则按工作空间配置：个人沿用 [ADR-0006](0006-open-registration-free-credits.md) 的积分，企业使用工作空间额度。
- Agent 对话、客户自助上传识图、家具布局规划、饰面铺贴等能力按工作空间开关，不按代码分支区分。
- 目录分公共与工作空间私有两层。企业的石材等品牌资料只属于该工作空间。
- 人工确认不是必经步骤。企业由成员确认后发布给客户，个人由用户自己确认，都走现有的候选、展示、选择、采用链路，只是确认人不同。

## 企业场景的范围

- 方案重心是地面、墙面、台面、楼梯等**饰面**的石材铺贴：规格、铺法、缝宽、起铺点、拼花、波打线和连纹。家具与电器只作为预设氛围道具，客户不能自由摆放。
- **铺贴方案**必须改变石材、规格、铺法或排版中的至少一项；与“布局方案必须改变家具摆放”同理，不把同款石材只调亮度称为新方案。
- 多楼层、楼梯和 CAD 矢量图纸导入随企业场景提升优先级，具体规格另行发布。
- 用料估算（面积、片数、损耗）尚未确定，不纳入本决定；在确定前继续遵守“不提供预算或报价模块”。

## 考虑过的替代方案

- **新建企业专用仓库**：边界最清楚，但要么从零重建已验收的底座，要么复制后两边分别维护。
- **企业先做小程序原生端**：入口更直接，但演示阶段企业尚未决定立项，小程序的主体与业务域名等条件也未确认；H5 可以先给企业看，之后由 web-view 承载。
- **只做企业版、删除个人场景代码**：短期更轻，但开放式的个人 Agent 平台是长期目标，以后需要重新引入身份、积分和自助流程。保留并暂停扩展的成本更低。
- **客户端只读、方案全部由企业成员制作**：实现最简单，但企业拿不到客户自助提交带来的线索，客户也无法自己得到结果。
- **客户端开放对话式 Agent**：体验最自然，但属于面向公众的生成式 AI 服务，需先完成备案或登记；首版以选项式调整代替。

## 影响

- [ADR-0002](0002-agent-led-consumer-workflow.md) 中“面向个人用户”的定位由本决定替代；其 Agent 主导、受限工具、执行层强制约束与确认规则继续适用于两种工作空间。
- 现有领域模型以家具为中心：房间只有地面颜色，墙没有面，风格材质只能作用于家具。饰面与铺贴需要新增领域对象和校验，不能把石材塞进家具材质替换。
- 企业品牌名称、石材素材和商业资料不提交到仓库；仓库是否保持公开另行决定。
- 个人用户的识图需要在没有人工兜底的情况下达到可用质量，面向公众提供生成式 AI 也有备案或登记要求。这两项是以后开放个人场景的主要门槛，不由本决定解决。
