# D09 离线演示数据与验收

日期：2026-11-03。范围：工单 #40。本机 PostgreSQL 14（独立库 `hestia_d09`）、Next.js dev（127.0.0.1:3101）、出图 Worker；短信为模拟发送，未配置任何模型。演示说明见 [stone-h5-demo.md](../demo/stone-h5-demo.md)。

## 实现要点

- **种子脚本** `pnpm demo:seed`（`scripts/demo-seed.ts`）经服务层创建：演示成员账号（邀请 + 接受，密码随机且不显示）、企业工作空间 `demo-stone`「演示石材企业」、5 款程序生成的示意石材、两份成员预置的示例别墅方案（`createMemberRequest`，全部通过排版校验即发布）、定向手机号分享（138 0013 8000）与绑定码分享（90 天链接，绑定码 48 小时）。
  - 幂等：预置方案使用固定操作标识，重复执行返回同一方案；分享令牌与绑定码只在创建时返回，脚本把它们存到 `private-data/demo/seed.json`（不提交），重复执行时链接仍可用（可预览、未绑定、绑定码未用且未过期）就沿用，否则撤销旧链接（留记录）后重新分享。
  - `--reset`：只删除演示企业下的方案需求、项目与出图、客户关系，以及演示手机号的登录会话和验证码记录，然后重新准备。这是脚本中唯一直接删除数据的部分，范围限定在演示企业和演示号码。
  - 默认在脚本内预生成预置方案的效果图（与 Worker 相同的执行函数），`--no-render` 交给 Worker。
- **部署配置**（ADR-0007，代码不按身份限制）：
  - `HESTIA_REGISTRATION=closed`：开放注册返回 403 `REGISTRATION_CLOSED`，不创建账号。注册接口原先未把业务错误转为 HTTP 状态（会返回 500），已与手机号接口一样处理。
  - `HESTIA_HOME_ENTRY=demo-stone`：根路径重定向到企业客户端，不显示工作台入口。
  - 演示用验证码额度 `HESTIA_OTP_MAX_PER_SOURCE`、`HESTIA_OTP_MAX_PER_PHONE`，`NEXT_TELEMETRY_DISABLED=1`，局域网演示 `HESTIA_WEB_HOST=0.0.0.0`，均写入 `.env.example` 与演示说明。
- **验收脚本** `pnpm validate:client-h5`（`scripts/validation/client-h5.ts`）：手机视口真实浏览器走完两条入口，拦截并报告一切非本机请求。
- 方案主图按渲染视口比例（1280:880，略裁去顶部）显示，效果图顶部的来源条不再与页面标签重叠；图注保留“效果图 · 示意素材”。

`validate:client-h5` 覆盖：根路径进入企业入口；定向分享未登录预览（预生成效果图）、调整需登录、指定手机号登录后自动绑定；切换方案与 3D；确认并留言；调整换石材 → 新修订出图中 → 提示需重新确认；另一手机号打开已绑定链接只能预览；绑定码错误提示剩余 4 次、正确码绑定；客户自助登录 → 示例别墅 → 饰面 → 石材 → 提交 → 出图（刷新后仍在出图页）；我的项目分组；伪造链接失效。截图逐页人工核对。

## 限制

- “断网”以浏览器拦截全部外网请求加服务端连接检查验证，未在本机物理断开网络；演示电脑上建议按说明断网再走一遍。
- 未在手机真机上核对，使用 390×844 手机视口。
- 无显卡时每张效果图约 1.5–2 分钟；`--reset` 会重新生成预置方案的 6 张效果图。
