## Problem Statement

> 2026-11-03 按 [ADR-0013](../../decisions/0013-drawing-requests-without-review-gate.md) 缩小范围：DXF 不再待审核。

排队中的照片、PDF、DWG，以及客户主动交给企业的图纸，需要成员在界面上整理户型后出方案；开启“全部审核后发布”的企业需要发布入口。

## Solution

实现辅助转换（整理队列）：查看客户的图纸，导入整理好的户型，导入后自动出方案并发布；仅对开启“全部审核”的企业显示审核发布。

## User Stories

1. As an 企业成员, I want 看到待审方案的效果图与提示后发布, so that 客户只看到可靠方案。
2. As an 企业成员, I want 为非 DXF 图纸导入整理好的户型, so that 这类需求也能出方案。

## Implementation Decisions

- 按获批原型的辅助转换页实现：下载客户原图 → 导入整理好的户型（HouseSpec JSON，D05 接口，校验结果与核对提示）→「确认户型并出方案」（`POST /api/workspaces/{id}/leads/{requestId}/generate`），通过排版校验的方案直接发布；不通过时把原因告诉成员，需求留在队列。
- 「今日」与线索列表的“待整理图纸”列出队列；只有开启“全部审核后发布”的企业，在线索详情显示“发布给客户”（二次确认）。
- 预留模型识别：以后在导入前增加“自动识别户型草稿”，成员核对修改后导入；首版不调用模型。

## Testing Decisions

- [x] 真实浏览器：客户上传照片 → 今日“待整理图纸” → 整理页下载原图 → 导入不合格户型被拒 → 导入合格户型 → 确认出方案 → 已发布、客户端可见。见 [W03 验证](../../validation/W03-drawing-queue.md)。

## Out of Scope

在界面中绘制或编辑户型。
