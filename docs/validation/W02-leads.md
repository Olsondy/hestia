# W02 线索列表与详情验证

日期：2026-11-03。范围：工单 #47。本机 PostgreSQL（127.0.0.1:54329）、Next.js dev（127.0.0.1:3000）。演示数据用 `pnpm demo:seed --reset --no-render` 准备（未预生成效果图），浏览器验收使用 Playwright Chromium。

## 实现要点

- **列表** `/w/{企业}/leads`：按原型的三个快捷筛选（请求联系、待审核 / 辅助转换、待批准绑定，带计数）、状态分段（全部、待审核、已发布、客户已确认）、跟进状态筛选与搜索（手机号、称呼、项目名）；筛选条件在地址栏，刷新保留；页头搜索回车进入列表。列为缩略图、项目 / 客户（脱敏手机号、来源、请求联系与绑定申请标记）、状态、跟进、最近动作，按最近动作排序。筛选在已读取的线索上进行（S02 的服务端筛选供后续分页使用）。
- **详情** `/w/{企业}/leads/{id}`：方案画面铺满，左侧面板悬浮，可收起。
  - 「方案」：方案列表（缩略图、摘要、修订 / 客户已确认 / 待审），所选楼层的硬装清单与排版提示。
  - 「客户与跟进」：完整手机号（成员可见）、户型、饰面、石材、偏好、说明；跟进状态单选、内部备注、跟进记录（备注与状态变更合并，按时间倒序）；客户动作（提交、确认、留言、请求联系、绑定申请）。
  - 「分享与绑定」：主客户、待批准申请、分享码（指定手机号 / 不指定、有效 / 已使用 / 已撤销 / 已过期、有效期）与操作记录。
  - 画面工具条可切换楼层、效果图 / 3D；3D 复用 `scene-runtime`（`SchemeViewer`），场景来自新增的成员接口 `GET /api/workspaces/{id}/leads/{requestId}/schemes/{schemeId}/scene`（客户与其他企业成员 404）。效果图用成员可见的出图结果。
  - 客户请求联系且线索仍是“新线索”时，面板底部提供“已回电，标记为已联系”；标记后线索移出「今日」的请求联系。
- **留待后续**：新建分享、批准 / 拒绝申请、撤销与解绑（W04），审核发布与辅助转换（W03），Agent 面板（W07），软装风格（K01、K02）。界面上相应位置只写明“稍后开放”，不放不可用的按钮。
- 演示石材名称去掉“（示意）”后缀，硬装清单标题统一标注“示意素材”（与 H5 一致）。
