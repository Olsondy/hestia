# 大陆优先的邀请制试用，以减少运维负担作为技术选型约束

> 2026-10-25 后续调整：用户确认开放注册，以简单积分提供免费体验，首期仍不提供付费功能，见 [ADR-0006](0006-open-registration-free-credits.md)。下文关于邀请制及暂不开放公众注册的描述保留为原始决策背景，已被该决定替代；其他约束继续有效。

用户在技术栈讨论中确认：首版以中国大陆用户无需代理即可正常使用为要求，兼顾海外；首次上线采用邀请制、多账号、独立项目的小规模试用，暂不开放公众注册及付费购买。项目主要由用户和 AI 开发维护，暂时没有固定团队或必须沿用的语言栈。

接受为减少运维工作使用付费托管服务，但优先选择低成本方案，保留数据导出及迁移能力。基础设施预算暂不设定；需先提供具体方案及费用组成，模型用量单独核算。不得把“预算未定”解释为已授权购买资源或无限用量。

这些前提约束 [技术方案](../web-stack.md) 和 [ADR-0003](0003-modular-monolith-with-durable-workers.md)。用户后来确认实现技术栈及邀请制邮箱密码登录，见上述文档；云厂商、托管数据库产品、具体地域和资源规格仍留待部署讨论。小规模试用不减少项目隔离、后台恢复与固定事实保护要求。

## 取舍

相比从一开始开放注册和自建全部基础设施，受控邀请与托管优先可以降低账号运营、数据库维护和部署工作量，代价是持续服务费用和一定供应商依赖。保留独立数据模型、迁移脚本及文件导出路径，避免把业务事实只保存在厂商专有工作流中。大陆访问体验必须在实际部署后验证，不能用“海外节点可以访问”替代验收。
